## 一、2026-10-15：综合组「整组一位」+ 任课映射扩容六科（v1.19.49.32）

### 1.1 学科组长：综合组改成「整组一位」
用户口径：*「综合组是一个组，所以他们只有一个学科组长。然后不分高一、高二、高三，直接整一个学科组长就可以了」*

- 体育 / 音乐 / 美术 / 信息技术 / 通用技术 / 心理 **六科合用一位组长**，不分年级、不分学科
- 矩阵里综合组由 6 行 × 4 列收缩为**一行一格**（键 `综合组|综合组`）
- 落库 `subject='综合组'` / `grade=''` / `category='综合组组长'`（新增第三类组长）
- 按年级（`高一|体育`）或按具体学科（`教研组|体育`）另开格子**一律被拒**（skipped，不落库）
- 候选＝六科教师并集（任课映射 → 课表 → 教师档案三级兜底不变）；导出年级列写「不分年级」
- 课表徽章：六科课表统一回查「综合组」那条登记并标「综合组组长」，文化科不受影响

### 1.2 任课教师映射：科目列 9 → 15 科
用户口径：*「教师映射可不可以扩容啊？增加这个综合组的」*

- 新增 `app/models/grades.py::LINK_SUBJECTS = SUBJECTS + COMPREHENSIVE_SUBJECTS`（15 科）
- **成绩链路继续只认 `SUBJECTS`（9 科）**：成绩导入白名单、分析报表、分数线、
  `DEFAULT_FULL_MARKS`、AI 成绩口径一律不扩；六科只在「映射维护 + 课表核对」里流动
- 矩阵接口返回 15 科 + `subject_groups`，页面按「文化科目 / 综合组」分组带渲染
- 保存白名单放开（原来填「体育」会被静默丢弃）；导入模板 +6 列；导入解析识别六科
  并归一常见写法（信息→信息技术、通用→通用技术、心理健康→心理 等）
- 课表导入的任课核对纳入六科（原口径明确跳过），比对前先归一科目名
- 字面别名唯一真值上移 `academic.COMPREHENSIVE_ALIAS`（组长服务与映射导入共用）
- 联动：学科组长页的综合组候选由此自动带出这六科老师

### 1.3 数据改动
**无表结构改动**；新增 1 个数据归并迁移 `scripts/migrate_leader_group_single_20261014.py`（A12，
无旧形态记录时空跑）。
