### 1.1 模块数据分离说明

系统采用模块化数据分离设计，各模块数据存储在独立数据库中（**任一模块异常不影响系统管理等其他模块**）：

| 模块 | 前端入口 | 数据来源 | 说明 |
|------|---------|---------|------|
| 系统管理 | `/students/`、`/users/` 等 | `system.db`（根基库） | 学生基础信息、教师账号、字典、权限等 |
| 宿舍管理 | `/dashboard/` | `dormitory.db` + `history.db` | 住宿与分配数据；变更历史独立存储 |
| 成绩管理 | `/grades/` | `grades.db` | 考试、成绩、划线、证明、考务、AI 报告 |
| 积分管理 | `/points/` | `points.db` | 积分记录 |
| 教务管理 | `/academic/` | `academic.db` | 教师名单、查课、业绩、课表 |
| 学生画像 | `/portrait/` | `portrait.db` | 占位（规划） |

**设计优势**：各部门独立管理自己的模块数据、互不干扰；学生基础信息统一维护；模块间通过学号关联，保证数据一致性。

## 三、宿舍管理模块

左侧菜单 → **宿舍管理**（或欢迎页点击"宿舍管理"卡片），进入宿舍仪表盘。

### 3.1 侧边栏导航
进入宿舍管理后，左侧显示宿舍专属菜单：学生查询 / 宿舍列表 / 分配宿舍 / 宿舍报表 / 床位分配 / 宿舍总览 / 统计报表。

### 3.2 学生查询
左侧菜单 → **学生查询**，支持按姓名、学号、年级、班级、性别组合搜索。

### 3.3 宿舍列表
查看所有宿舍，按楼栋/性别/楼层/床位数筛选。

**合班宿舍标识**：班级名含 `+`（如 `01班+02班`）即为合班宿舍，列表自动显示黄色"合班"徽标，无需手动设置。

### 3.4 新增宿舍
点击"新增宿舍" → 选择楼栋、房间号、性别、床位数 → 保存。支持批量新增。

**宿舍编辑（分配班级）**：班级选择框支持多选，选中 2 个及以上班级（如 `01班` + `04班`）保存后，系统自动识别为合班宿舍：
- 班级名自动拼接为 `01班+04班`（按班号排序，不分主次）
- 宿舍列表 / 详情 / 可视化分配 / 互换弹窗 / 统计报表 **全站自动显示合班**
- 同一宿舍的合班班级，其学生均可入住该宿舍（跨班防护自动放行）
- 合班详情（各班级人数份额）仅在自动分配时生成

### 3.5 分配宿舍给班级

- **可视化分配**：拖拽班级到宿舍房间。同一房间拖入多个班级，保存后自动聚合为合班宿舍（如 `02班`+`01班` 自动整理为 `01班+02班`）
- **自动分配**：见下（4 步向导）

#### 3.5.1 自动分配 · 4 步向导

入口：侧边栏 → **分配宿舍**（`/rooms/assign-auto`）。

**第 1 步：选择年级和性别**
页面左侧显示所有在校年级（按新→旧排列），每个年级下展示各班级的男生/女生住校人数。
1. 勾选要参与分配的年级（可多选）
2. 系统自动列出该年级所有班级的住校男/女人数
3. 点击「全选男生」/「全选女生」快速勾选；也可单独取消某个班级的某个性别

> 💡 只有标记为"住校"的学生才会出现在列表中。走读生不参与宿舍分配。一次分配**仅允许勾选一个年级**（防止跨年级混住，系统前后端双重校验）。

**第 2 步：选择宿舍房间**
1. 选择目标楼栋（如"男生宿舍楼"、"女生宿舍楼"）
2. 选择楼层（可多选）
3. 系统列出符合条件的所有空闲房间，勾选要使用的房间（或全选）

页面实时显示：已选宿舍数量、床位数（分男/女）、剩余空余宿舍数、容量是否充足；**各级别缺口提示**（"L=7 还缺 X 床≈N 间"）。
> ⚠️ 若提示"有效容量不足"，说明所选房间床位总数少于学生人数，需增选宿舍。
> 面板含**「高级参数」**（默认折叠）：7 项评分权重 + 迭代轮数，可按学校偏好调整（如调大"满8"更坚决不满员、调大"班级分散"让班级更集中）。

**第 3 步：预览分配方案**
点击「生成预览」后展示：分配结果表（每间房分配到哪个班级、预计住几人）、压力模式（L=6/7/8）、合班宿舍（特殊颜色标注）、算法日志（含迭代轮数/评分/收敛说明与合班调整记录）。
- 可手动调整合班宿舍位置（推挤排序）
- 确认无误后点击「执行分配」

**第 4 步：执行分配**
- 系统将班级信息写入房间记录（年级、班级、合班信息）
- 后续可在「床位分配」页面为具体学生安排床位号
- ⚠️ 执行后如需重新分配，选择"覆盖模式"清除已有分配

#### 3.5.2 自动分配 · 算法说明（v8：初稿 + 迭代爬山 + 评分选优）

**核心原则**：同班集中（S 型连续房间）· 性别隔离 · 年级分层（高年级低楼层）· 宽松优先 · 压力均匀。

**全局压力等级（L=6/7/8）**：

| 等级 | 模式 | 8人间住几人 | 说明 |
|------|------|:---------:|------|
| L=6 | 宽松 | ≤6 | 优先：舒适优先，8人间也只住6人 |
| L=7 | 紧张 | ≤7 | 床位不足时整体升档 |
| L=8 | 极限 | ≤8 | 最终兜底 |

- 系统从 L=6 开始，取第一个满足"床位总数 ≥ 学生人数"的等级；实际分配时若"房间不足"（收尾班级占房过多）自动升档重试
- **所有房间（含合班房）统一升档**，不会出现"普通房6人、合班房8人"的失衡

**核心特性**：
- **严格分级初稿**：L=6→7→8 逐级贪心，6 人间住满 6、8 人间按 L；房间不足自动升档
- **迭代爬山**：每轮枚举所有可行"人员移动/交换"，执行评分下降最多的操作，持续优化直到收敛
- **全局评分（7 项权重）**：宽松优先 / 8人间超6人 / 满8（8人间住满重罚） / 合班宿舍 / 班级分散 / 小房(≤3人) / 空房——分数越低越好，前端"高级参数"可调（含迭代轮数，默认 1000）
- **收敛检测**：连续 20 轮未刷新最优自动停止（含抖动跳出 + 历史最优回滚）
- **填充优先级**：同层小容量房间（6 人间）优先住满；班级收尾**优先填满本班独享宿舍空床**，全部住满后才发起合班

**合班规则**：仅同年级 + 同班型（普通班/卓越班/强基班分开）的班级可合班；每间合班房 ≤2 个班；每班最多发起 1 次合班（被借不算）；合班宿舍记录各班床位份额（如 `07班+08班`：07班4人、08班4人），分床位时按份额分配。

**合班宿舍自动调整**：多个班级连续收尾产生的"链式合班"会被自动优化（中间班独立成房、两端重组合班），减少合班数量。例如：
```
调整前: 01班+02班(02班1人)、02班+03班(03班1人)、03班+04班(04班1人) → 3间合班
调整后: 01班+04班(04班1人) + 02班独立6人 + 03班独立6人 → 1间合班
```

**房间分配顺序（S 型序列）**：偶数层正向（201→202→…→223）、奇数层反向（323→322→…→301），楼层升序连接；同班级房间在序列上连续（物理相邻）。

**多年级**：一次分配仅限一个年级（系统强校验）；如需分批，先分高年级再分低年级。

#### 3.5.3 两种分配模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| **保留已有** | 跳过已分配的房间，只分配空房间 | 补充分配（如新增学生） |
| **覆盖全部** | 清除所有已选房间的分配信息，重新来过 | 重新分班、学期调整 |

> ⚠️ "覆盖全部"会同时清除这些房间内的床位分配记录，请谨慎使用。

### 3.6 宿舍报表
查看按年级/性别/班级组织的分配总览，支持导出 Excel。

### 3.7 床位分配
选择年级班级 → 拖拽学生到空床位。支持一键自动分配、搬移、互换。
**限制**：性别必须匹配、非合班宿舍仅限本班学生。

### 3.8 统计报表
全校/年级/班级三级视图，展示男女比例、住校走读分布。

### 3.9 分配操作建议
1. **先分高年级再分低年级**：宿舍楼有限时，先给毕业班分配（低楼层），再给新生分配
2. **预留空房**：不要把所有房间都选上，预留几间作为后续调整空间
3. **同楼栋同性别**：选择房间时确保楼栋性别与学生性别匹配
4. **分配后检查**：预览阶段仔细查看合班宿舍是否合理，不满意可调整后重新预览
5. **学期初统一分配**：建议在全员到校后一次性分配，避免频繁覆盖

## 四、成绩管理模块

左侧菜单 → **成绩管理**（含三个入口：成绩分析 / 考试管理 / 任课教师映射；划线分层入口在考试详情内）。

### 4.1 入口与角色可见范围

| 菜单 | 权限 | 作用 |
|---|---|---|
| 成绩分析 | `grades.view` | 四大分析页（表格 + 图表 + 导出 + 打印 + AI 分析） |
| 考试管理 | `grades.edit` | 新建考试、导入成绩、浏览/修正成绩、删除考试 |
| 任课教师映射 | `grades.teachers` | 维护「班级 × 科目 → 教师」映射（教师分析的数据来源） |

系统按**身份（权限组）× 子功能三档**与**数据范围（勾选年级）**共同决定可见性：

| 角色/身份 | 能看到的分析页 | 数据范围 |
|---|---|---|
| 管理员 | 四个 tab 全部 | 全部年级全部考试 |
| 年级长 | 四个 tab | 仅本年级 |
| 班主任 | 仅「班级分析」 | 仅所辖班级（可看「本班 vs 年级均值」对标） |
| 任课教师 | 仅「任课教师」 | 仅本人任教的「班级 × 科目」组合 |
| 教务员（按年级分工） | 依权限（般为成绩写入） | 仅被勾选的年级（如仅 2025 级） |

> 用户级数据范围优先于身份的原范围规则；没有可看权限时分析页提示「您没有成绩查看权限」；任课映射未维护时「任课教师」页有维护引导。

### 4.2 标准作业流程

```
考试管理 → 新建考试
   →（考试详情）下载模板 / 上传成绩 → 预检报告 → 确认导入（自动重算排名）
   → 划线分层配置（保存划线）
   → 成绩分析（四 tab 查看 / 导出 Excel / 打印 PDF / 可选 AI 分析）
```

依赖顺序：**新建考试 → 导入成绩 → 重算排名 是强序**（没考试不能导入，没导入不能分析）；**划线分层**在分析前做才有分层与上线指标；**任课教师映射**独立维护，看「任课教师」tab 前需维护好。

> 班主任、任课教师通常只做最后一步「成绩分析」；前面的考试与成绩由管理员/年级长维护。

### 4.3 考试管理

**新建考试**：填写年级（必选，如 `2026级`）、考试名称（必填，建议含日期）、考试日期、考试类型（月考/期中/期末/联考/开学考/模拟/其他）。**同年级同名考试会被阻断**（避免成绩分散到两场）。
> 考试状态：`未导入` / `已导入` / `待重算`（单条改分后）；新建/导入/重算/删除均记录操作日志。

**考试列表**：按日期倒序显示参考人数与状态，顶部可按年级筛选。

**考试详情（浏览与单条修正）**：按班级、按方向排名展示全体成绩（含总分、各单科、方向排名、进退步）。
- 单条修正：点「编辑」改分或补录；设为空 = 视为缺考删除。单科改分会**自动重算该生总分行**。改后考试变 `待重算`。
- **单条改分后必须点「重新计算排名」**（否则排名/进退步是旧的）；整场确认导入会自动重算。
- 成绩单默认每页 50 行（可选 100/200/全部）。

**删除考试**：需**输入考试名称二次确认**，级联删除该场全部成绩与划线。不可恢复，删除前建议备份。

### 4.4 成绩导入（最核心）

**下载模板**（含 3 个 sheet）：模板 A（全年级全科：学号/姓名/年级/班级/总分 + 9 科）、模板 B（分批次分科）、填表说明。

**填表要点（必读）**：
1. 第一行是表头，**不能改列名、不能删**；缺考科目留空；0 分填 `0`
2. **学号必填**（系统以学号匹配学生）
3. **年级列可选**：填了就必须与考试年级一致，不一致的行被拦截；不填按考试年级处理
4. **总分列可选**：填了优先采用外部总分；不填由系统按应考科目累加
5. 科目列可只保留本次要导入的科目（**分批导入**），未出现的科目列不会被改动
6. 历史方向班级不考物理/化学/生物，对应格留空即可；可直接粘贴参考 Excel 整表，多余列自动忽略
7. 错误行（表头识别失败/学号匹配不到/分数越界等）**全部跳过、不阻断整批**，可下载错误明细修改后重传

> 应考 6 科 = 语数外 + 方向科 + 选科组合 2 门；选科写法支持 3+1+2 简称（物化生/史政地…）、全称分隔、文理、不分科/全科/统一/留空（＝全部 9 科）。

**导入向导与两种模式**：
```
模式 A 增量覆盖（推荐，日常）
   影响范围 = 文件出现的(学生 × 科目列)
   ├─ 有分 → 覆盖旧值；该科列空 → 删旧行（视为本次缺考）
   ├─ 文件未出现的科目 → 保留旧值（支持分批补导）
   └─ 文件未出现的学生 → 默认保留（可勾选「一并移除」，慎用）

模式 B 整场重置（纠错）
   先清空本场全部成绩 → 再只按本次文件导入（上次整体导错时用）
```

**预检报告（关键确认环节）**：展示识别结果 + 统计卡（可导入人数/错误行/将新增/将更新/将删除/未出现保留）+ 错误明细下载。核对差异无误后点 **确认导入**（二次弹窗）→ 事务写入并**自动重算排名与进退步**。
> 一次导入最多 16MB；文件仅内存解析不落盘；导入失败自动回滚。

**分批补导注意总分口径**：总分 = 应考科目中**已有成绩**之和（尚未导入的科目按 0 计）——科目未导齐时分析页顶部有黄色提示；单科分析不受影响。

### 4.5 划线分层配置

入口：**考试详情 → 划线分层**（管理员/年级长可用）。配置后分析里的分层计数、各班上线人数/上线率才会出现。

- **先选分层模板（推荐）**：选模板后表格立即按该模板的层重建；比例/名次模板会把默认值预填；保存划线即**绑定考试↔模板**；未绑定的考试会**按考试类型自动匹配**模板（优先级：已绑定 > 按类型匹配 > 默认四层）
- **分层模板管理**（侧栏「分层模板」）：新建/编辑/删除；项目：模板名、下界方式、层（可增删/上下移，第 1 层最高）、适用考试类型；内置「四层」「高考线」不可删
- **三种下界方式**：固定分数（如 614.3）/ 人数比例%（如前 20%）/ 人数名次（如前 50 名）
  - 比例与名次**先换算成实际分数线再保存**，按**方向内**换算；边界同分一并计入
  - 校验方向：固定分数从高到低；比例/名次从小到大；末层填 0 表示「其余全部」
  - 切换下界方式会清空已填值（系统弹确认）；保存前前端逐列预校验

### 4.6 成绩分析（四 tab）

顶部筛选栏按 tab 联动显隐（年级/考试/方向/班级/科目）。默认按权限进入第一个可见 tab 并选中最近一场已导入考试。

- **年级分析**：各班汇总表、**各班分层上线统计表**（「前几名每个班有多少人」看这张）、科目总表、分数段/名次段分布、历次总览；图表：班均分柱（含年级均值线）、分数段堆叠、箱线图、历次多折线
- **班级分析**：班级概况、班-年级科目对标、学生历次明细（含进退步）、分层统计；图表：本班 vs 年级柱、总分直方图、走势折线（含年级参照线）、各科得分率雷达图
- **学科分析**：学科各班对比、历次统计、总分分层内该科得分；图表：班级×科目热力图、同科各班对比、均分/及格率双轴折线
- **任课教师**：教师教学数据（班均分/年级差/及格率/优秀率）、历次跟踪；图表：同科教师对比、本人走势。仅客观数据，变动列用颜色标注（进步绿/退步红），不出现评价性文字

**导出与打印**：当前页签全部表格可导出 Excel（多 sheet 含口径说明）；打印仅当前激活页签，选「另存为 PDF」即可。

### 4.7 汇报区、考务管理与个人成绩查询（进阶功能）

**成绩汇报区**（管理员/年级长）：面向校级汇报的五大板块（各科层上线 / 班级概况 / 单班各科 / 单科各班 / 压线提醒）+ PPT/HTML 交付物导出。

**考务管理**（考务人员）：左侧「考务管理 → 考务批次」，流程对应 Excel 宏《考场学生考号与考场信息编排》：
1. **学生名单**：下载模板（已按年级预填）或导入；字段含固定考场/座号/自定义考号
2. **考场设置**：维护考场编号/位置/适用选科/容量/考号前缀（「默认/通用/空」科目对所有选科开放）
3. **编排与考号生成**：模式 0 前缀+考场+座号 / 模式 1 学号即考号 / 模式 2 自定义；规则：固定考场座号学生优先，其余按选科分组、**同班邻座 ≤1** 分配
4. **导出**：按班级/按考场名单、竖版桌签（打印预览 + Excel）
5. **成绩关联**：绑定同年级考试后按考场查看总分/排名/进退步，缺成绩标「缺」

**个人成绩查询与成绩证明**：按学生查询历次成绩与趋势 → 生成**带防伪码的成绩证明**（快照固化，防篡改）→ 打印或公开核验页验真（脱敏展示）；证明台账支持作废管理。

### 4.8 任课教师映射

入口「任课教师映射」（`grades.teachers`）。：「任课教师」分析的数据来源。

- **网页矩阵**：选年级 → 矩阵（行=科目，列=班级）下拉选教师（仅已启用账号）→ 快捷：整行设为 / 整列填充 → 保存全部（预览绑定/变更/停用后生效）
- **批量导入教师安排表**：上传《教师安排表》（可多年级分段；英语→外语别名；非高考科目/正副班等列忽略）→ 逐 (年级,班,科) 按姓名核对账号：命中 → 绑定；停用/重名 → 错误行；无账号 → **自动开户**（账号=拼音可改、随机初始密码、强制改密）→ 预览开户清单（密码仅一次可见，可下载《账号开通清单》）→ 确认生效
- 教师真实姓名不可修改（身份锚）；账号（如改手机号）可改，不影响映射

### 4.9 AI 分析（可选，需自备或管理员公共 API Key）

> **数据提醒**：分析时本次与上次考试的原始成绩会发送到 AI 服务商（离开学校内网）；报告仅供参考，不代表学校评价结论。

1. **配置 Key**：个人 Key（推荐，加密存储仅本人可见）或管理员公共 Key（未配个人 Key 的用户自动使用）；支持 DeepSeek / 自定义 OpenAI 兼容服务商
2. **生成报告**：选好考试 → 点「AI 分析」→ 发送确认弹窗（展示范围/人数/密钥）→ 生成（约 30–90 秒）→ 渲染到页签顶部，可复制/关闭，同时写入历史
3. **报告历史**：「AI 报告」菜单查看（本人报告；管理员看全部），可按考试筛选、删除

### 4.10 成绩模块异常与回退汇总

| 现象 | 流程位置 | 处理 |
|---|---|---|
| 同名考试建不了 | 新建 | 改考试名称 |
| 整批导入报错 | 解析 | 下载模板，核对表头/学号列 |
| 部分行进错误报告 | 解析校验 | 下载错误明细，改后重传（错误行不落库） |
| 误覆盖 / 旧行残留 | 模式 A 差异预览 | 确认前核对「更新/删除/未出现保留」；必要时用模式 B 重置 |

### 4.11 成绩口径与术语

- **年级**：`2026级` 格式，不认「高三/高二」称谓
- **方向**：物理 / 历史（排名/分层/上线均按方向内计算，互不可比）
- **应考科目**：默认 3+1+2 共 6 门；文理固定 6 门；「不分科/全科/统一」或留空＝全部 9 科
- **参考学生 / 参考数**：本场至少一门应考科有分的学生；**借读等不剔除、不影响统计与排名**，仅作徽标标注
- **缺考**：应考科目无成绩（留空），计 0 参考、不参与该科统计
- **方向排名**：物理类/历史类内各自按总分降序，同分同名次（竞争排名，顺延跳号）
- **进退步**：本次方向排名 − 上次同方向考试方向排名（负数=进步）；首场/无上次为「—」
- **分层 / 层**：按总分把方向内参考学生切分为有序若干层（默认四层：优秀/良好/及格/待提升），层名与层数可配
- **科目三线**：优秀线/及格线/低分线，默认 = 满分的 90% / 60% / 40%
- **得分率**：科目均值 ÷ 该科满分（跨科可比用）
- **分数段 / 名次段**：总分等距分段（默认 30 分一档）；方向内名次区间（默认 1–10/11–20/…/201+）

> 完整的算法与指标公式（排名/分层判定/比例换算等）见《成绩分析算法手册.md》。

- **功能权限（表格一）**：身份 × 子功能 × 三档——**不可见 / 只读 / 写入**。格子点击切换（灰=不可见、蓝=只读、绿=写入），支持细分控制（如班主任可"床位分配"但不给"宿舍分配"）
- **数据范围（表格二）**：按人员勾选可见**年级**（如"2025 级教务员"仅可见 2025 级数据）；未勾选按身份的原范围规则
- **身份可自由新建**：点"新建身份"即建新角色，随后配置其权限即可
- **防误操作**：管理员组为系统保留身份（不可修改与删除，单元格锁定）

### 9.6 年级管理
**毕业操作**：清空该年级的宿舍和床位分配，同时备份主数据库（`dormitory.db`）和分配历史库（`history.db`）到 `data/backups/`，方便日后追溯。
**历史查询**：查看历史毕业备份数据。

### 9.7 寝室分配历史
系统自动记录每次床位分配、取消、搬移、互换、清空操作。记录保存在独立的历史库中，包含学生快照、房间信息、操作人、学期等字段，即使学生被删除仍可追溯。每学期重新分寝时的历史数据永久保留。

## 十、常见问题

### 宿舍分配
**Q: 提示"有效容量不足"怎么办？** 说明所选房间床位总数 < 学生人数。增选更多楼层/房间，或减少参与分配的学生。
**Q: 为什么出现了合班宿舍？** 班级剩余人数不够独占一间房时，系统将两个班的零散学生合并到一间房，属正常现象，算法会尽量减少合班数量。
**Q: 为什么有些班级出现在两个合班宿舍？** 班级收尾人数较少时（如 1~3 人）可能被拆分并入两个合班宿舍，这是床位限制下的较优解，不违反"每班最多发起 1 次合班"规则。
**Q: 8人间什么时候住满8人？** 系统宽松优先：默认所有房间（含8人间）只住6人；所选房间床位不足时整体升档 7 人/8 人，不会出现"有的房6人、有的房8人"失衡。
**Q: 预览时勾选的宿舍为什么有些没用上？** 启用 L=8 极限模式时，算法按 S 型序列用最少房间装下所有人，序列靠后的宿舍可能闲置，属正常行为。
**Q: 分配后如何调整？** 房间级在「宿舍列表」手动改；床位级在「床位分配」拖拽调整；整体在自动分配里选"覆盖全部"重分。
**Q: 只想重新分配某个年级？** 可以。第 1 步只勾选该年级，模式选"覆盖全部"；其他年级房间不受影响（只要不选那些房间）。
**Q: 为什么某些学生没有出现在分配列表中？** 只有"住校"、班级非"已转出/不分班"、年级未标记"已毕业"的学生才会出现。

### 成绩与账号
**Q: 分析页年级/考试下拉是空的？** 确认该年级已有"已导入"状态的考试；仍为空按 `Ctrl+F5` 强刷。
**Q: 切换 tab 后内容错位/空白？** 多为浏览器缓存，`Ctrl+F5` 强刷。
**Q: 导入后排名没变/进退步不对？** 单条改分后需点"重新计算排名"；整场确认导入会自动重算。
**Q: 分层表不显示/学科图没有参考线？** 先到考试详情做"划线分层配置"并保存。
**Q: 改了分数/划线但分析页数字没更新？** 分析接口有短缓存，稍等或强刷。
**Q: 保存划线提示"页面已过期或安全校验未通过"？** 页面打开太久/服务器重启致安全令牌失效，刷新后重试。
**Q: 班主任/任课教师看不到某些 tab？** 属正常权限限制（见第四章 4.1），非故障。
**Q: 忘记管理员密码？** 运行 `python scripts/init_db.py` 仅会补建缺失数据（管理员、字典、宿舍），不会覆盖已有数据；重置密码请先备份数据库后重新初始化。
**Q: 身份证号显示为空？** AES 加密存储，旧明文数据自动兼容读取。
**Q: 导入 Excel 报"学号为空"？** 学号是跨模块业务主键，不能为空。
**Q: 导入 Excel 报"身份证号格式不正确"？** 身份证号必须 18 位且校验码正确。
**Q: 每学期重新分寝后，之前的分配记录还在吗？** 在。系统自动在独立历史库中记录所有分配变更；毕业操作也会备份历史库。
**Q: 教师看不到自己的课表/业绩？** 确认该账号已在教务「教师名单」中关联（手机号与账号一致）；未关联时工作台会显示引导提示，请联系管理员。
