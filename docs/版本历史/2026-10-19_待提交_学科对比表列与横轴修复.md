## 一句话概述

「学科各班对比表」首列改班级、删重复的「X线人数」、表头改短，
图表横轴用班级；右栏紧凑表字号与宽度回归常规，历次表考试名去长前缀。

## 改动清单

### 修复

- `app/modules/grades/services/tab_service.py` `subject_tab()`：
  - 删除恒为当前学科的「科目」列（整列相同，占掉首列）；
  - 删除每层的「X线人数」（落层人数，互斥）——最高层该值与
    「X线单上」完全相等，低层又容易被误读成上线人数；
  - 每层只留累计口径「X上线 / X双上」两列；
    「双上率%」等于双上÷人数，不再单列；
  - 表头统一缩短：人数 / 均分 / 最高 / 低分 / 均分差 /
    本科率% / 特控率% / 特控上线 / 特控双上 / 本科上线 / 本科双上；
  - `class_compare` 增加 `chartHint`（横轴=班级，只画均分 + 两率），
    修掉横轴出现十几次「语文」的问题。
- 同一函数「历次考试统计表」：
  - 考试名去掉年级前缀与末尾「（学期）」，
    如 `2025级20260318限时练（高一下）` → `20260318限时练`；
  - 表头改为 人数 / 均分 / 本科率% / 特控率%；
  - 增加 `chartHint`（横轴=考试，只画均分 + 两率），
    不再让 500 量级的参考人数把柱子压平。

### 优化

- `app/static/css/grades.css`：
  - 图表视图右栏（紧凑数据表）字号 18px → 12/12.5px、
    内边距收紧，并取消 760px 最小宽度 → 12 列可一屏放下
    （实测 scrollWidth = clientWidth = 676px）；
  - 图表宽度 42% → 38%，把空间让给数据表（仍是左图右表）。
  - 表格视图（整表）仍保持 18px，不受影响。
