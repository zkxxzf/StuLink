# 待提交 · 限时练长表表头吸顶（2026-10-21）

> 状态：草稿（待提交）
> 起因：用户截图「学生成绩」表翻到下面，`学号/姓名/班级/语文…` 表头滚没了

## 一句话概述

学生成绩、学生分析这两张长表，页面往下翻时**表头固定在顶部导航下方**，
列宽与表体逐列对齐，深浅色主题都跟随表头底色；切班级 / 翻页（局部刷新）
后自动重建。

## 为什么不用 CSS `position: sticky`

表格外面包着 `.table-responsive`（`overflow-x: auto`）。CSS 规定
`overflow-x` 不是 `visible` 时，`overflow-y` 会被算成 `auto` —— 这个容器
成了**滚动容器**，`thead th { position: sticky }` 只会相对它定位；它自己
不滚动（高度由内容撑开），所以表头跟着整页一起滚走，看起来完全没生效。

## 做法（`app/static/js/timed_pane.js`）

- `buildSticky()`：页面加载 / 局部刷新后，克隆 `thead` 到一个
  `.timed-sticky-head` 的 fixed 容器里；逐列取原表头 `getBoundingClientRect().width`
  设到克隆列上（`table-layout: fixed`），保证列宽严格对齐；
- `syncSticky()`：页面滚动时判断原表头是否已滚过 `top: 56px`（顶部导航高度），
  是则显示克隆层；同步 `left / width`（表格在侧栏右侧）与横向滚动偏移
  `translateX(-scrollLeft)`；
- 底色取原表头 `th` 的计算样式；取到透明就退回 `body` 背景（深色主题下
  实测 `rgb(37,49,73)`，与表头一致，不会透出下面的行）；
- 监听 `scroll`（页面 + 表格容器）、`resize`；`paint()`（局部刷新替换面板）
  成功后调 `afterPaint()` 重建，避免切班级后引用已移除的旧表；
- `pointer-events: none`，不挡鼠标；`@media print` 时不显示（打印走整表）。

## 验证（沙箱真实数据 No.43 / 50 行一页）

| 项 | 结果 |
|---|---|
| 滚到 900px | 吸顶层 `display: block`，`top: 56`，`left: 244`，宽 1172 |
| 列宽对齐 | 原表 `[126, 85, 64, 74, 74]` ＝ 吸顶层 `[126, 85, 64, 74, 74]` |
| 切到 05班（局部刷新）+ 下滚 | 吸顶层重建，仍然 `display: block` |
| 深色主题 | 吸顶层底色 `rgb(37,49,73)` ＝ 表头 `rgb(37,49,73)`，无透出 |
| 浅色/深色截图 | 表头文字完整、列未串位 |

冒烟 32 通过 / 0 失败（新增「timed_pane.js 含吸顶表头逻辑」）。

## 2026-10-21 补丁：表头跑到页面最下面

**现象**：用户截图上吸顶层出现在**页脚下方**（页面最底部），而不是顶部。

**原因**：克隆层只靠 `base.html` 里的 `.timed-sticky-head` 规则定位。模板内联
CSS 不走 `?v=` 版本号，浏览器可能还在用旧 HTML 缓存 → 规则不存在 →
`position: fixed` 没生效，`appendChild(document.body)` 的 div 就落在 body 末尾，
也就是页脚下面。

**修法**：`buildSticky()` 把 `position / top / left / width / height / z-index /
overflow / display / box-shadow` 全部写成**内联样式**，不再依赖样式表；
`top` 取导航栏 `nav.navbar` 的实际高度（默认 56px）。

**验证**：滚到 900px、滚到页面最底部、以及**手动删除样式表里
`.timed-sticky-head` 规则**（模拟旧缓存）三种场景，克隆层都是
`position: fixed / top: 56px / left: 244 / 在视口内`。

## 影响与风险

- 需要重启服务：不用（只改前端静态资源，但 `?v=` 启动时才刷新 → 需重启）
- 数据库迁移：无
- 已知限制：表头有两行（`rowspan/colspan` 复杂表头）时，克隆层只保证
  总高度一致，内部行高可能与原表有 1px 差异；限时练两张表都是单行表头，不受影响。
