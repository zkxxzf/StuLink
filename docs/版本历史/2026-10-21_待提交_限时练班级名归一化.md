# 待提交 · 限时练导入班级名归一化（任课教师不再空白）（2026-10-21）

> 状态：草稿（待提交）
> 起因：用户截图「成绩总体分析」里十个班的**任课教师整列都是「—」**

## 一句话概述

智学网导出的班级写「高三01班」，而任课映射 / 班型 / 历史成绩都写「01班」，
两边对不上 → 按班级名分组时查不到老师。现在**入库统一归一化成「01班」**，
老数据在展示层同样归一化兜住，不用重新导入。

## 根因（实测数据）

| 来源 | 班级名写法 | 例子 |
|---|---|---|
| 智学网导出的 CSV（新抓的语文） | 带年级前缀 | `高三01班` … `高三10班` |
| 之前手工导入的数学/外语、任课映射、班型、ClassProfile | 只有班号 | `01班` … `10班` |

`_teacher_map()` 用 `{班级: 教师}`，key 取映射里的 `01班`；分析行 key 取成绩里的
`高三01班` → `teachers.get('高三01班', '')` 恒为空。

同一场里还因此出现两套班名（语文在「高三01班」、数学外语在「01班」），
班级筛选按钮会重复，「01班」与「高三01班」还会被拆成两行。

## 改动

- `timed_import._norm_class()`（新增，`_code` 旁边）：
  `高三01班` / `1班` / `高一（02）班` → `01班`；`不分班` / `未分班` 原样。
  `parse_sheet()` 解析时直接归一化，**新导入的数据存的就是「01班」**。
- `timed_match` 删掉自己那份 `_norm_class`，改从 `timed_import` 引入（一份口径）。
- `timed_analysis` 展示层全部归一化（老数据兼容，不用改库）：
  `subject_analysis()` 分组、`_teacher_map()` 的 key、`_trim_quotas()` 的 key、
  `classes_of()` 去重、`_summary_base()` 的班级/班级名次、`_trends_base()`、
  `student_detail()` 的班级显示。

## 验证

- 真实数据（No.43 语文，10 个班）：`classes_of` 只剩 `01班…10班`，
  分析页任课教师全部出来 —— 01班 刘稳、02班 刘明哲、03班 何漫漫、04班 刘明哲、
  05班 刘稳、06班 李悦、07班 何漫漫、08班 李悦、09班 刘凡星、10班 刘凡星；
- 去差均分不变（01班 89.5、06班 91.4 …，与改前一致，只是班名统一了）；
- 回归 `tests/timed_exam_regression.py`：**55 通过 / 0 失败**（新增 5 条：
  `高三01班`/`1班`/`高一（02）班` 归一化、`不分班` 原样、解析后已归一化）；
- 冒烟 31 / 0。

## 影响与风险

- 需要重启服务：是；数据库迁移：无（新导入自动归一化，旧数据展示层兼容）
- 风险：极少数把「高三」当班级名一部分的学校，导出后会显示成 `01班` ——
  与任课映射/班型同口径，属于预期的统一。
- 若要彻底清掉库里的旧写法，可跑一次性 SQL（可选，不做也不影响展示）：

  ```sql
  UPDATE timed_scores SET class_name = REPLACE(class_name, '高三', '')
  WHERE class_name LIKE '高三%班';
  ```
