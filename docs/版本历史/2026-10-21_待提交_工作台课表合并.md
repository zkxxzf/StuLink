# 待提交 · 教师工作台「两张课表」合并成一张（2026-10-21）

> 状态：草稿（待提交）
> 起因：用户反馈「老师工作台为啥有俩课表啊」——截图里首屏右边是
> 「今日课程」、下面又是「我的课表」，同一份课表数据出现两次。

## 一句话概述

工作台首页删掉「今日课程」卡片，把今天那几节课并进「我的课表」卡
（**今天置顶 + 强调色高亮**，今天没课也写明「今天没课」），一张卡回答
「今天上什么」+「本周怎么排」。

## 改动清单

### 修复

- `app/templates/workbench/index.html`：删除「今日课程」卡片。它与
  「我的课表」同源（后端同一句 `schedule_service.get_teacher_view`），
  今日即课表数据里 `weekday == today.isoweekday()` 的子集，属重复展示。
- 同文件「我的课表」卡：
  - 行序改为 `[今天] + 周一…周日（排除今天）`，今天那一行用
    `.today-row`（`--sl-soft-info-bg` 底 + `--sl-soft-info-bd` 描边）
    高亮，星期徽标由「周三」改为「今天」；
  - 今天没有课时显式输出「今天没课」，不再是整块空白；
  - 重复的「查看完整课表 →」按钮只保留一个（原两张卡各挂一个）。
- 布局：首行改为 欢迎卡（5）+ 我的课表（7），宽度与原「今日课程」卡
  一致；第三行只剩班主任工作记录卡，改整行（12）。
- `app/modules/workbench/routes/__init__.py`：`today_entries` 不再计算
  （模板也不用），`weekday_today` 一并删掉；页面渲染参数同步。

## 影响与风险

- 需要重启服务：是（模板与 `.py` 均有改动，本机非 `--dev` 不热加载）
- 数据库迁移：无
- 已知副作用：首页首屏不再单独出现「今天几节课」的大卡片，改为在
  课表卡第一行高亮；小程序首页的「今日课程」聚合接口未动。
- 部署注意：浏览器强缓存时按 Ctrl+F5。
