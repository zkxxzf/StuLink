# v1.19.65.66 · AI 报告工具调用与空报告修复（2026-10-23）

> 状态：已提交（v1.19.65.66）
> 相关：`docs/设计手册/成绩管理设计手册.md` §4.9.1

## 一句话概述

修 AI 报告的两种「看不到报告」：模型把工具调用写成 DSML 文本被当正文渲染；
模型整篇输出 HTML 文档被消毒器连正文一起吞掉、只落一条空报告。

## 改动清单

### 新增

- `app/modules/grades/services/ai_text_tools.py`：解析文本态工具调用
  （DSML / `<tool_call>{json}</tool_call>`），并负责从正文中整块剔除。

### 修复

- `ai_agent.py`：只认 `message.tool_calls`，中转把调用写进 `content` 时
  被当最终报告 → 解析成 tool_calls 后**真正执行**，结果拼成一条 user
  消息回灌；收尾轮加“禁止再调工具”；无法解析时给明确错误而不是贴标签。
- `utils/html_guard.py`：`html` / `body` 曾在“连内容一起丢”名单里，
  模型整篇输出 `<!DOCTYPE html><html>…` 时正文全被吞掉（只留一个换行）
  → 两者改为只丢标签本身、正文保留；`<body>` 开始即结束 head 丢弃状态。
- `ai_agent.py`：消毒后为空白按失败返回，不再下发空报告。
- `ai_task_service.py`：空白 `html_text` 按 error 处理、不写 `ai_reports`。

### 优化 / 重构

- 提示词补一句“只给 HTML 片段，不要整篇文档外壳”，降低复发概率。
