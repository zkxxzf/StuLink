## 一句话概述

成绩首页去掉两块统计图表，顶部改为可自定义的功能入口板：所有成绩页面路由
集中登记，涉及考试的入口点开先选考试，显隐与顺序按用户保存在
`system_settings`（不建表、不迁移）。

## 改动清单

### 新增

- `grades/services/entry_defs.py`：**成绩页面路由清单**（30 条入口，
  分考试管理 / 单场考试 / 成绩分析 / 个人与证明 / 基础配置五组），
  每条带权限 key、是否需要选考试、是否只列已导入场次。
- `grades/services/entry_catalog.py`：`url_for` 生成链接与 `__EXAM__` 模板、
  按权限 + 业务门槛过滤、合并用户偏好。
- `grades/services/entry_prefs.py`：偏好读写（`grades_entries_u<uid>`）。
- `routes/dashboard.py::home_entries_save`：`POST /grades/api/home-entries`
  保存入口显隐与顺序（只接受目录内的 key）。
- `static/js/grades_home_entries.js`：选考试弹窗（搜索 + 已导入过滤）、
  自定义弹窗（勾选 + 上下移 + 恢复默认）。
- 首页模板新增入口板、选考试弹窗、自定义弹窗与芯片样式。

### 优化 / 重构

- `grades/dashboard.html`：删除「各年级考试次数」「各类别参与人数」两块
  图表（含表格），入口板放到页头下方（用户口径「顶部是各种入口」）。
- 指标区由两行（3 张 KPI 卡 + 4 张场次卡）合并为**一行 7 格指标条**
  （3 项总览 + 限时练/期中/期末/月考），高度约 150px → 82px；
  窄屏自动折成 4 列 / 2 列，用每格的 inset 线画分隔（换行不漏灰块）。
- `static/js/grades_dashboard.js`：去掉 ECharts 渲染、年级/类别表格渲染，
  只保留 KPI / 场次卡 / 最近考试 / 动态的局部刷新；同时移除
  `echarts.min.js` 的引入（该页不再需要图表库）。
- 权限口径不放松：入口按 `user.has_perm(perm)` 过滤；「考试概览·成绩单」
  另过 `services/scoresheet.visible` 门槛，避免「看得见点不进」的 403。

## 影响与风险

- 需要重启容器：是（新增 `.py`、改模板与 JS）
- 数据库迁移：无

  数据仍由 `/grades/api/dashboard` 返回（保留给后续复用），只是页面不画。
