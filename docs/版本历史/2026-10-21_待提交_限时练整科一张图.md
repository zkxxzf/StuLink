## 一句话概述

限时练成绩总览分析里，一个学科的「人数」与「去差均分」两组图 + 表
不再各给一个「下载图片」，改为**卡片头部「复制图片 / 下载图片」两个动作，
共用同一张整科 PNG**（复制进剪贴板可直接粘贴，或存成文件）。

## 改动清单

### 新增

- `app/static/js/timed_tbl_canvas.js`：把任意 HTML 表格画成离屏 Canvas
  （`window.timedTableCanvas(table)` → `{canvas, width, height}`），
  从 `timed_copy_image.js` 抽出来复用，单文件不再膨胀。
- `timed_analysis_charts.js` 暴露 `window.timedAnalysisCharts.exportURL(el)`：
  在屏幕外建临时 ECharts 实例（420×520、强制浅色配色），出白底 PNG 后
  `dispose()`。**不改动页面上那张图**，深浅主题都不受影响。
- `timed_copy_image.copyImage()`：`ClipboardItem` + `navigator.clipboard.write`
  复制 PNG；非安全上下文（局域网 http）或旧浏览器给出明确提示，引导用
  「下载图片」。

### 修复

- `_analysis.html`：一科两个「下载图片」按钮 → 卡片头部「复制图片」+
  「下载图片」两个动作（共用一份 `data-*` 元信息，一个 `data-timed-meta`）。
- 导出图缺图表：旧版只画表格，图要用户自己截；现在图 + 表在同一张图上。
- 深色主题导出为白底时轴文字会「白底白字」：导出实例固定浅色配色。

### 优化 / 重构

- 图表导出宽度 420（页面窄栏按 250 渲染），12px 轴标签不再挤成一团。
- 表头/斑马纹/合计行样式与原表格 PNG 一致，页脚保留来源与时间戳。

## 影响与风险

- 需要重启服务：是（模板 + 静态资源带 `?v=` 版本戳）
- 数据库迁移：无
- 已知副作用：「复制图片」需要安全上下文（https 或 localhost）；局域网
  裸 http 访问时浏览器不提供剪贴板接口，会提示改用「下载图片」。
- 部署注意：浏览器强缓存时按 Ctrl+F5
