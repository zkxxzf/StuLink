# 待提交 · AI 报告分享链接 + 深色看板视觉（2026-10-22）

> 状态：草稿（待提交）
> 起因：用户提出「AI 分析能不能分享，做成链接，别人打开链接登录即可查看」，
> 并希望页面 UI 参照其提供的数据看板（深底 + 金色章节眉标）。

## 一句话概述

AI 报告新增**可撤销的分享链接**（`/s/<token>`，未登录先跳登录、登录后自动回到报告；
只读一页，不暴露工作台），同时把报告画布与分享页改成**深色看板皮肤**
（编号章节、金色标题、深色表格），导出 HTML 同步换肤。

## 改动清单

### 新增

- `app/models/grades.py`：`AiReportShare` 表（`ai_report_shares`）——
  token / 有效期 / 撤销时间 / 访问计数。**一个报告同时最多一条有效链接**。
- `app/modules/grades/services/ai_share_service.py`：
  token 生成（`secrets.token_urlsafe`）、复用/新建、解析、撤销、访问计数、
  报告删除时清理。访问计数按会话去重，刷新不刷量。
- `app/modules/grades/routes/ai_share.py`：
  - `GET/POST /grades/ai/reports/<rid>/share`（仅报告所有者）
  - `POST /grades/ai/reports/<rid>/share/revoke`
- `app/modules/share/`（新蓝图）+ `app/templates/share/`：
  - `GET /s/<token>`：登录即可看（不要求 `grades.view`），失效原因分
    不存在 / 已撤销 / 已过期 / 报告已删除，统一 410 文案。
- `app/static/js/ai_share.js`：分享弹窗逻辑（有效期 7/30/90/长期、复制、
  预览、撤销、访问统计）。
- `app/static/css/ai_board.css`：深色看板皮肤（分享页 + 报告画布 + 弹窗）。

### 修复

- `app/modules/grades/routes/ai.py`：删除报告 / 删除任务 / 清空记录时
  同步 `purge_for_report()`，避免分享行指向已删报告。
- `app/modules/grades/routes/ai.py`：`/ai/tasks/<tid>` 与 `.../stream`
  此前写死 `<int:tid>`，Werkzeug 不接受负号 → 列表里「旧口径报告」
  （`-report_id`）点开一律 404；改为字符串接收后 `int()` 校验。
- **任务「已完成」但报告行不存在 → 报告区白屏**（2026-10-22 用户截图）：
  `_task_json` 增加 `report_missing` 标记，前端显示「这份报告的内容已不存在，
  请重新生成」；删除报告时同时解除 `ai_tasks.report_id` 指向。
- **模型返回 Markdown 时报告显示成源码**（2026-10-22 用户截图）：
  旧兜底只把整段文本包 `<p>`，`# 标题` / `**加粗**` / `| 表 |` 原样显示。
  新增 `app/utils/md_guard.py`（受限 Markdown→HTML，与 `grades_md.js` 同口径），
  并在「生成时 / 任务详情 / 历史报告列表 / 分享页」四处统一走
  `normalize_report_html()`；历史 `kind=html` 但正文是 Markdown 的脏数据
  （含被 `<p>` 包住的情况）也会在读取时自动转成排版好的 HTML。
- `app/templates/grades/ai_studio.html` 的分享提示：`<i>` 与文字被 flex
  挤成竖排 → 文字包 `<span>` 并给图标固定宽度。

## 影响与风险

- 需要重启服务：是（新增蓝图、模板、静态资源）
- 数据库迁移：A47（本地已执行）
- 已知副作用：分享链接**任何能登录的账号**都能打开（用户明确要求）；
  因此弹窗里明确提示「报告可能含学生姓名与成绩，请确认可以外发」。
- 部署注意：反向代理下链接取浏览器当前源拼接（后端只返回 `/s/<token>`），
  换域名不需要改数据；`ai_board.css` / `ai_share.js` 为新增静态资源，
  `?v=` 在启动时按 mtime 生成。
