# v1.19.49.46 · 2026-10-20 · 考试「年级学期」标签、列表筛选与名称自动带阶段

## 一句话概述

考试名称里手写的「（高三上）」升级为独立字段与标签，历次考试可按
**学期 / 类型 / 考试日期区间**筛选，新建考试的名称自动带阶段
（`2024级20261010月考`）。

## 改动清单

**新增**

- `exams.grade_semester`（高一上…高三下，空 = 按日期自动推算）。
- 历次考试列表：名称右侧一个学期胶囊标签；名称列自动剥掉
  「与标签完全一致」的末尾括号（其它括号原样保留）。
- 新建 / 编辑考试：年级学期下拉（首项「自动」），选年级与日期时
  实时预览推算结果；前端春节表由后端注入，前后端同一算法。
- 列表筛选：`?grade=&sem=&type=&d1=&d2=` 五个 GET 参数，
  学期 / 类型 / 日期区间收在同一条筛选栏里。
- 小程序 `exam-new` 页面：同样的学期 picker（`semesters` 由接口下发）。

**修复**

- 旧口径「2 月起算下学期」把 **2024级 2026-02-06 期末考**误判为高二下；
  按春节口径改为高二上，成绩证明矩阵行标签一并修正。
- `term_of_date` 原先在 `utils` 与模型层各写一份，现收敛到模型层。

**优化**

- 默认名称生成：「年级 + 日期」→「年级 + 8 位日期 + 阶段」
  （后端 `_auto_exam_name()` 与表单实时预览同规则）。
- 筛到空结果时给「清空筛选条件」入口，不让人困在空页。

**脚本**

- `scripts/migrate/migrate_exam_grade_semester_20261020.py`：幂等加列，
  **不回填**（历史场次按推算值展示，与名称末尾括号逐条核对一致）。

**文档**

- `CODEBUDDY.md` 增加「考试年级学期标签口径」一节。
- `docs/规范与说明/数据库迁移清单.md` 登记 A24；
  `deploy/nas_migrate_pending.sh` 加执行行。
- `docs/聊天总结/20261020_批次总结_考试年级学期标签_v1.19.49.39.md`。

## 影响与风险

- **必须重启容器 / 进程**（模板与蓝图都在启动时加载）。
- **有迁移**：`exams.grade_semester`，幂等、可重复执行；生产待执行。
- 学期口径变化会影响「成绩证明」矩阵的分组标签（高二下 → 高二上），
  属修正，不影响分数与排名。
- 小程序需按常规流程重新构建（改的是 `miniprogram/` 源码）。

## 回滚方式

- 数据：迁移前备份 `data/grades.db.bak-20261020_145828`。
