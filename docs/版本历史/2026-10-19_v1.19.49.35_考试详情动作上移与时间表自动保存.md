## 一句话概述

① 本场考试标题固定到页面顶部导航栏，在成绩单 / 数据导入 / 划线分层 / 分析等
本场考试页面一直显示；原页头位置改回各页面自己的标题。成绩单的管理动作——
**数据导入 / 重新计算排名 / 划线分层 / 删除考试**——仍在页头右侧。
**分数修改记录**从该页撤下，改在**数据导入页**以卡片展示最近记录
（可点「查看完整记录」）。
② 考务环节⑤ 考试时间表**改完即自动保存**：日期 / 科目 / 开始 / 结束 /
选科 / 备注失焦就存，行尾不再有「存」按钮。

## 改动清单

### 优化 / 重构

- `app/templates/base.html`：导航栏在考试上下文（`exam_nav()`）下固定展示
  考试标题、状态与年级/性质/日期；浅色/深色主题都跟随导航文字色。
- `app/templates/grades/exam_detail.html`：顶部不再放动作按钮；页头显示
  「成绩单」标题、当前筛选人数、编辑考试和动作按钮（数据导入 / 重算 /
  划线分层 / 删除）。
- `app/templates/grades/import_wizard.html`：新增「分数修改记录」卡片
  （最近 N 条 + 完整记录入口）；`routes/exams.py::data_import_context`
  同时下发 `change_logs` / `change_log_count`。
- `app/templates/grades/affairs/detail.html`（环节⑤）：
  - 删除行尾「存」按钮（模板渲染与 `addScheduleRow` 两处）；
  - `schedBody` 的 change 事件在完成时间自动带出后调用 `autoSaveSched`；
  - 同一行用 Promise 串行保存，连续改字段时后一次一定带上前一次写入的
    id，避免新行重复插入；
  - 没选科目时不保存，提示「科目必填」；保存成功在 `schedMsg` 闪
    「已自动保存」；
  - 导入前的「未保存」提醒改为只看"选了科目却没存成"的行。

## 影响与风险

- 需要重启容器：是（模板）
- 数据库迁移：无
- 已知行为：新行在**选完科目**那一刻才首次落库；只填备注不选科目
  不会产生记录（科目必填）。
- 边改边导航：未完成的 fetch 可能被浏览器取消，下次改同一字段会重新保存。
