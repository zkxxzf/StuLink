# 待提交 · 成绩单页补「导出数据」按钮（2026-10-21）

> 状态：草稿（待提交）
> 起因：用户反馈「成绩单缺少一个导出数据的按钮」

## 一句话概述

成绩单页（`/grades/exams/<id>`）右上角新增「导出数据」，把**页面当前筛选与
排序**下的全部学生成绩导成 Excel；数据范围与页面同源（含班级收敛），
不会成为绕过「逐生总分收口」的旁路。

## 改动清单

### 新增

- `app/modules/grades/routes/scoresheet_export.py`：`GET
  /grades/exams/<id>/scores/export`，`grades.view` + `_scoresheet_scope`
  （无可用班一律 403）；`cls / dir / sort / order` 与页面同一套白名单校验，
  导出不分页（全部匹配行），写审计日志。
- `app/modules/grades/services/scoresheet_xlsx.py`：工作簿排版。主表「成绩单」
  列＝页面列（学号/姓名/考号/班级/方向/选科/方向排/进退步/班排/总分 + 九科）；
  首行合并写口径（考试、范围、排序、人数、符号含义）；本场有原始分时另起
  「原始分」表（总分原始分 + 各科原始分）。

### 优化 / 重构

- `routes/exams.py::_exam_page_rows()`：新增 `all_rows` 参数（导出用，不分页），
  并把每页取科目的 `IN (...)` 改为 500 一块——整年级导出时学号上千，
  避免触碰 SQLite 变量上限。**页面路径行为不变**（默认 `all_rows=False`）。
- `templates/grades/exam_detail.html`：工具栏加「导出数据」按钮（`btn-sm
  btn-outline-success`），链接带上当前 `cls / dir / sort / order`。

### 文档

- 本条目 + `版本索引.md` 一行。

### 脚本 / 数据库

- `scripts/smoke_grades.py`：新增 3 条断言（能下 xlsx 且行数=全部学生、
  按班筛选生效、页面有按钮且指向导出路由）。
- 无迁移、无新表、无脚本。
