## 改动清单

### 修复

- `app/utils/trash.py`、`app/modules/system/routes/trash.py`：
  新增 `purge_expired_records()`；过期清理支持 dry-run、删除前导出 JSONL 元数据、
  只删 `expires_at` 非空且已过期的行；管理页清理复用同一逻辑。
- `scripts/ops/prune_trash.py`：命令行清理入口，默认 dry-run；
  `--apply --confirm DELETE` 才删除。
- `mcp_server/core/auth.py`、`mcp_server/config.py`、`mcp_server/config.json`：
  认证通过后按“账号+来源 / token 来源”做读请求频控（默认 120 次/60 秒），
  超限返回 429 + `Retry-After`；`read_rate_limit=0` 可关闭。
- `app/modules/grades/routes/exam_affairs.py`：考务重排前整组快照
  （`affair_arrange_before`），归档失败中止；重排异常回滚，旧编排仍可用。
- `app/modules/dormitory/services/room_assignment_v8.py`：自动分配「覆盖模式」
  清空房间/床位前快照（`dorm_assign_before`），归档失败中止。
- `app/utils/trash.py`：`archive_snapshot(..., update_existing=True)` +
  快照恢复按原 id **更新**现有行（不再插入重复行）；先提交业务行再写
  `restored_at`，避免 system bind 双连接互锁。
- `app/__init__.py`：CSP 默认 `enforce`，补 `form-action 'self'`、
  `frame-src 'none'`、`media/worker/manifest-src`、`img-src blob:`；
  `STULINK_CSP_MODE=report` 可回退，`STULINK_CSP_NONCE=1` 为后续 nonce 迁移预留。
- `requirements.txt`：新增 `defusedxml~=0.7.1`。
- 新增 `requirements.lock` / `mcp_server/requirements.lock`：全量依赖固定版本 + hash；
  `Dockerfile` / `Dockerfile.mcp` 改用 `pip install --require-hashes`，基础镜像升到 Python 3.12。
- 新增 `app/utils/xml_safe.py`：XML 解析统一入口（defusedxml）。
- 新增 `scripts/check_xml_parsers.py`：禁止业务代码直接 `xml.etree` / `lxml`，
  已挂进 `scripts/run_all_regression.py` 自检（6 项）。
- `app/models/ai_usage.py`、`app/utils/ai_quota.py`：AI 每日配额
  （user_id × day，SQLite `BEGIN IMMEDIATE` 原子自增）。
- `app/modules/grades/routes/ai.py`、`ai_import.py`、
  `services/ai_task_service.py`：分析、追问、AI 任务提交、AI 导入建议统一计数；
  超限返回 429 / 跳过 AI 建议。
- `app/modules/grades/services/ai_service.py`、`config.py`：
  `AI_REQUEST_TIMEOUT`（默认 180s）用于普通/流式调用；`AI_DAILY_QUOTA`
  （默认 50，0=关闭）。

## 影响与风险

- 需要重启容器：是。
- 数据库迁移：A22（加表），生产部署新代码前执行；本地已执行。
- 行为变更：
  - MCP 认证通过后限流，脚本批量请求可能收到 429；
  - 回收站清理默认 dry-run，管理页清理会先写 `data/backups/trash_*.jsonl`；
  - 考务重排/宿舍覆盖模式多一次归档写入，失败会中止；
  - CSP 默认 enforcing；若页面有遗漏的外链资源会被浏览器拦截，
    可临时 `STULINK_CSP_MODE=report` 回退；
  - AI 每人每日默认 50 次，超限 429；
  - AI 单进程同时最多 6 个任务，满槽直接拒绝（不是排队）；
  - 容器健康检查改调 `/health`，DB 异常会显示 unhealthy。
- 已知副作用：无（回归全绿）。
