## 一句话概述

成绩模块新增「限时练」：**三张独立表**存放场次 / 单科成绩 / 名次区间模板，
考试列表拆成「普通考试 / 限时练」两个 tab，限时练只做
**追加式单科导入 + 单科分析**，普通考试的全部链路零改动。

## 改动清单

### 新增

- **数据模型** `app/models/timed.py`：
  - `timed_exams`：场次（年级 / 日期 / 学期 / 分层模板 / 导入草稿）；
  - `timed_scores`：单科成绩，`(exam_id, student_no, subject)` 唯一，
    `score` 非空（缺考不落库），带全年级单科名次 `rank_grade`；
  - `timed_band_templates`：限时练专属**名次区间**模板。
  - 三张表都不写 `exams` / `exam_scores`，类型由"落在哪张表"锁定，
    没有可切换的模式列，两类之间不存在互转入口。
- **侧栏独立入口**：成绩模块侧栏在「历次考试」下面新增「限时练」，
  指向 `/grades/timed`；**普通考试列表页不加 tab**，其查询 / 筛选 /
  分页 / 导出代码一行未动。
- **限时练态侧栏**：进入某场限时练后，侧栏与普通考试完全同款 ——
  悬浮流程栏（返回限时练列表 → 场次名 → 三步进度圆点 → 页签导航），
  顶栏同时固定场次名与「已导入/未导入」状态。上下文由
  `app/utils/timed_nav.py` 提供，外观复用 `.efn-*` 样式，没有第二套 UI。
- **新建分开**：普通考试新建页只建普通考试（阶段下拉不再出现「限时练」，
  历史场次若本就是「限时练」则保留该选项，避免编辑时静默改值）；
  限时练在自己的列表页点「新建限时练」进入独立表单。
- **命名**：侧栏与页面里的「历次考试」统一改称 **「大型考试」**
  （与「限时练」对照）；只改显示文案，表结构 / 字段 / 路由不变。
- **改分入口已移除**：随着「成绩单」页删除，`/timed/<id>/score/<sid>` 改分与
  删除成绩两个路由（及 `routes/timed_edit.py`）一并删除；分数有误时
  **重新导入该科覆盖**（同科重导 = 整科覆盖，已由回归测试覆盖）。
- **限时练页面**（`app/templates/grades/timed/`）：
  - 列表：年级胶囊 + **学期下拉（默认只看本学期，可切全部学期）** +
    已导入科目 + 人数（**去重学生数，不是成绩行数**）+ 状态；
  - 详情 3 个页签：**学生成绩 / 数据导入 / 成绩总览分析**
    （「成绩单」页已删除；没有考务页，也不进入普通考试的四步流程）；
  - **学生成绩 = 汇总表**：一行一个学生，列 = 学号 / 姓名 / 班级 /
    各科分数 / **总分** / **年级名次** / **班级名次** / **T 分数**；
    总分由各科现算（限时练不存总分行），名次按总分降序同分并列，
    班级名次在同班内再排；顶部可按班级筛选，**支持导出 Excel**；
  - **T 分数**：T = 10×Z + 50（Z =（个人分 − 同群体均分）÷ 标准差）；
    **每科分数下方浅色小字 = 该科 T 分（同科内比）**，总分下方 = 总分 T 分；
    50=平均、60=高一档、40=低一档；某科实考 < 30 人时该科不算；
  - 分层：固定使用内置「限时练名次分层」，层数与普通考试模板一致
    （**12 层：前10/前20/前50/前80/前100/前150/前200/前250/前300/前400/前500/前550**），
    口径 = **累积门槛**（名次 ≤ N 的人数）；不提供选模板 / 自定义 / 分数线；
  - **分层按人数自适应（保底机制）**：实考 < 100 人时按 **10 人一组**
    重新分层（前10、前20…刚好覆盖全体，如 85 人 → 前10…前90）；
    ≥ 100 人时沿用模板，但**门槛超过实考人数的层不显示**
    （497 人 → 前10…前400，不出现前500/前550）；
  - 分析：**每个学科直接展开一块**（不再按科目切换），每块 **两组「图 + 表」** ——
    ① **人数**：左 = 各班各名次段的**人数堆积图**（ECharts 堆叠柱），
    右 = 人数表（班级 / 任课教师 / 人数 + 12 层人数）；
    ② **平均分**：左 = 各班平均分柱状图，右 = 平均分表
    （班级 / 任课教师 / 平均 / 最高 / 最低 + 12 层的**层内均分**）；
    每张表可单独**下载图片**（Canvas 自绘，无第三方依赖），
    表格不设内部滚动条（要完整截图 / 复制）。
  - 堆积图用**互斥区间**（相邻两层累计人数之差），避免"前10 ⊂ 前20"
    重复堆叠；各段相加 = 该班人数（末层固定「全员」，不再有"未入层"）。
  - **学生分析**（新增页签）：一人一行，学号/姓名/班级/平均 T + 每科一条
    **T 分迷你轨迹**；行内折线是后端算好坐标的**纯 SVG**（不初始化图表），
    点整行跳**学生详情页**（该生本年级全部场次成绩 + T 分走势，ECharts 折线）；
    分页 20 人/页、回溯最近 8 场。
    数据一次查全年级所有场次成绩、内存按 (场次,科目) 算 T，避免 N×M 次查询。

### 性能（2026-10-20 用户反馈"比较卡"后优化）

- **瓶颈不在数据库**：`timed_scores` 全表 14,284 行一次读出仅 0.01s；
  卡在两点 —— ① 分析页一次性初始化 **9 科 × 2 = 18 个 ECharts**；
  ② 每次请求都重算名次 / 每科 T 分（纯 Python 遍历 + 每科 500 次均值方差）。
- **前端懒加载**：图表用 `IntersectionObserver`（`rootMargin: 300px`），
  滚到可视区才 `echarts.init`，首屏通常只画 1~2 张；关掉动画；
  堆积图隐藏 13 段图例（窄图布局最耗时的部分），名字靠 tooltip 看。
- **服务端进程内缓存**（`timed_analysis._cached`，TTL 120s，键含场次/年级）：
  汇总表全量、每科分析块、学生趋势、学生详情都缓存；
  导入（`save_subject`）与删除场次时 `invalidate()` 主动清空（跨场次派生数据，
  直接整表清最安全）。
- **实测（test_client）**：`students` 57→5、`trends` 108→4、
  `analysis` 73→7、学生详情 28→2 ms（命中缓存后）。
- 趋势页不再生成已经用不到的行内 `detail` JSON（改跳独立详情页）。
- **导入能力**（`services/timed_import.py` / `timed_ai.py`）：
  - 模板文件导入：`考号 · 学号 · 姓名 · 班级 · 分数`；
  - AI 智能导入：AI 只回答"哪一列是什么"，逐行解析仍走确定性代码；
  - **考号优先**：先按 `students.zhixue_no` 匹配，未命中再按学号
    （含前导 0 数值兜底）；姓名/班级不用于猜测，避免同名误配；
  - **缺考文字摒弃**：`缺考 / 未考 / 免考 / — / 带括号说明` 等一律视为
    无成绩，不报错、不落库、页面也不再显示"缺考"二字。

### 修复（本批自查 + 独立审查发现的 9 项）

- `timed_service.can_manage` 原用数据范围兜底，会让"校长 / 教务员"等
  只读范围身份获得改分权 → 改为只认 `grades.edit` / `grades.score_edit`。
- 列表页年级筛选误用写校验函数 → 拆出 `assert_grade_readable`。
- AI 导入成功未清 `import_draft/import_token` → 旧预览页可能覆盖新导入。
- 分层模板维护改成「固定内置」后，模板接口 / 弹窗 / JS 已全部删除
  （不保留无入口的代码）；内置模板仍按名判重、幂等创建。
- `ensure_builtin_templates` 在只读渲染里 commit → 并发首访唯一键冲突 500，
  加 `IntegrityError` 回滚 + 回查。
- AI 导入表头不在第 1 行时会把表头当数据 → 按映射列反推表头行。
- 分数列名是「语文/数学」时 `_locate_header` 不认 → 同上兜底。
- 成绩单删除按钮把学生姓名拼进 `confirm()` → 姓名含引号时断字符串，
  改为不含姓名的固定文案。
- Canvas 导出长文本溢出到相邻列 / 空表高度重叠 → `fillText` 传 maxWidth、
  空表按一行高度计算。

### 优化 / 重构

- 仪表盘 KPI 的「限时练」改按 `timed_exams` 计数
  （原按 `exams.exam_type` 关键词，独立表后会恒为 0）。
- 导入预检沿用普通考试的"草稿 + 一次性 token"模式，确认页显示
  新增 / 改分 / 移除 / 错误 / 缺考五项差异。
- 改分、删成绩、整科覆盖后**自动重算该科全年级名次**（同分并列 1,1,3）。
