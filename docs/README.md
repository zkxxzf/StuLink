## 二、目录结构

```
docs/
├── README.md                  ← 你在这里
├── 设计文档.md                 ← 系统总体设计（架构 / 数据模型 / 模块划分）
├── 设计手册/                   ← 各业务模块的设计手册 + 算法手册（9）
├── 规范与说明/                 ← 部署、迁移、版本号、权限、协作、用户手册（9）
├── mcp/                       ← MCP 只读服务的文档与排查（4）
├── 审计报告/                   ← 九轮全项目审计 + 修复批次 + 安全整改总账（17）
├── 测试报告/                   ← 功能点击 / 并发性能 / 历史测试（3）
├── 方案与改造/                 ← 一次性改造方案与执行计划（5）
├── 版本历史/                   ← 版本记录（唯一真值，见其 README）
└── 聊天总结/                   ← 每次协作的批次总结（按日期）
```

## 三、各目录要点

### `设计文档.md`（根）
系统级总览：技术栈、分层架构、模块边界、数据库模型。**改架构先改这里。**

### `设计手册/`
| 文档 | 说明 |
|---|---|
| 成绩管理设计手册 | 成绩导入、划线分层、分析页、汇总打印、全局对比 |
| 教务管理设计手册 | 查课 / 调课 / 审批 / 业绩库 / 教师工作台 |
| 德育管理设计手册 | 奖惩、德育积分 |
| 宿舍管理设计手册 | 宿舍分配、调整、历史记录 |
| 系统管理设计手册 | 用户、角色、权限、系统参数 |
| 教师工作台设计手册 | 教师端首页与待办 |
| 学生画像设计手册 | 画像维度与计算 |
| 成绩分析算法手册 | 均分/上线率/位次/分层/进退步的**口径与公式** |
| 宿舍分配算法手册 | 分配与调换算法 |

### `规范与说明/`
部署文档、数据库迁移清单（**上线必读**）、版本号管理规范、权限体系说明、
教务模块权限说明、协作指南（分支/提交/审计流程）、用户文档（面向老师）、
AI 工具安装与配置指南、课表导入模板说明。

### `mcp/`
MCP 只读服务（12 个成绩分析工具）：技术文档（工具与参数）、成绩分析权限设计、
认证与授权设计、接入排查（宿主机 IP 访问 421）。

### `审计报告/`
按时间顺序的审计与修复记录。**看结论先看最新的**（第九轮 / 第八轮 / 第七轮），
看总账看 [审计报告_20261013_全项目.md](审计报告/审计报告_20261013_全项目.md)，
安全遗留看 [00-security-todo-merged.md](审计报告/00-security-todo-merged.md)。
详见 [审计报告/README.md](审计报告/README.md)。

### `测试报告/`
全站点击测试（2026-10-15）、200 并发性能测试（2026-10-15）、
历史测试报告（v1.7.1，仅存档）。

### `方案与改造/`
权限体系多身份改造（设计与执行计划）、寝室分配历史记录与日志系统、
调课三页面改造、考试数据快照完整性方案。

### `版本历史/` 与 `聊天总结/`
- **版本历史**：哪个版本、做了什么、为什么、怎么验证、怎么回滚。**唯一真值**，
  命名 `YYYY-MM-DD_vX.Y.Z.W_主题.md`，规则见其 README。
- **聊天总结**：每次协作的批次总结，按 `YYYYMMDD_批次总结_主题_版本.md`。

## 四、维护约定

1. **新增文档先想放哪**：模块设计 → `设计手册/`；审计/测试 → 对应目录；
   一次性方案 → `方案与改造/`；版本记录 → `版本历史/`；**不要往根目录丢**。
2. **根目录只留 `README.md` 和 `设计文档.md`**。
3. 移动/改名文档后，必须同步更新引用（代码注释里的 `docs/xxx.md` 也要改）。
4. 审计与测试报告**只增不删**（历史留证），过期的在本文档里标注"仅存档"。
5. 版本发布必须在 `版本历史/` 写一条，并更新 `版本历史/版本索引.md`。
