# 教师工作台设计手册

> 版本：v1.18.2.1（2026-09-24）｜状态：**开发中**（占位文档，待补全文）
> 所属模块：`workbench`（无独立库，只读汇聚）｜页面前缀：`/workbench`
> 文档体系：`设计文档.md`（总手册）→ 本手册（模块手册）

## 1. 模块定位与边界

**做什么：** 全体教师（登录用户）的个人工作页面——我的信息（编号/学科/手机号修改/身份证状态）、今日课程、我的课表、我的业绩（提交与查看）、班主任工作记录（占位）。
**不做什么：** 不持有独立数据库；不直接修改教务/成绩数据（只读汇聚 + 少数自有操作如手机号修改）；仅展示本人数据。

## 2. 数据库设计

**无独立库。** 数据来源：
- `academic.db / teachers`（本人教师记录，`teacher_of_user`：user_id 精确关联，兜底唯一同名自动补关联）
- `academic.db / teacher_achievements`（本人业绩）
- `academic.db / timetable_entries`（本人课表，按 teacher_uid 过滤）
- `system.db / users`（登录账号）

## 3. 权限与数据范围

- **无需权限点**：所有登录用户可访问（仅本人数据，无跨人暴露）
- 手机号修改：密码确认 + 全局唯一校验（同步 `users.username` 与 `teachers.phone`）——即"登录名自改权"
- 业绩提交：`status=pending` 待教务审核；账号未关联教师名单时显示引导提示

## 4. 核心流程与页面

`/workbench/` 单页（卡片式）：
1. 我的信息（教师编号只读、学科、手机号修改弹窗、身份徽章显示所属身份）
2. 今日课程（按当天星期过滤课表；无数据时占位提示）
3. 我的课表（按星期分组徽章展示）
4. 我的业绩（列表 + 提交弹窗，含审核状态徽章）
5. 班主任工作记录（占位，仅班主任视角提示建设中）

## 5. 与其他模块的数据交互

- **读入：** 教务（教师记录、业绩、课表）、平台（登录账号）
- **写出：** 手机号修改（users + teachers.phone）、业绩提交（academic.db）
- **对外提供：** 无（纯个人页面）

## 6. 故障隔离自检

| 场景 | 影响面 |
|------|--------|
| `academic.db` 损坏 | 工作台显示"未关联"引导；手机号修改不可用；其他模块不受影响 |
| `system.db` 正常性 | 登录、权限判断依赖 system（根基库），异常为全局问题而非本模块问题 |
