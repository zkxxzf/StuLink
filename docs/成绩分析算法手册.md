## 1. 术语表（全文统一口径）

| 术语 | 定义 |
|---|---|
| 年级 | 与主库字典一致，如 `2024级`/`2025级`（全校格式统一；**导入文件中的年级只认此格式**，不认"高三/高二/高一"等称谓列） |
| 班级 | `01班`~`10班`（年级+班级成对使用，班级不跨年级复用） |
| 方向 | 选科方向：`物理` / `历史`（源：字典 `subject_direction`、班型设置 `class_profiles.subject_direction`） |
| 选科组合 | 如 `物化生`、`史政地`（源：学生 `subject_selection`，12 种组合见字典） |
| 考试科目（9 科全集） | `语文、数学、外语、物理、历史、化学、生物、政治、地理`（字典 `exam_subject`，固定显示顺序） |
| 应考科目 | 某学生某场考试的应考集合 = 语数外 + 方向科（物理/历史二选一）+ 选科组合中 2 门再选科，共 6 门 |
| 参考学生 / 参考数 | 该考试中至少有一门应考科目成绩的学生；**不分学籍状态**（借读等一律计入），凡导入有分即统计 |
| 缺考（科目） | 应考科目无成绩（导入单元格留空） |
| 方向排名 | 物理类内部、历史类内部各自按总分（或单科）降序排名；同分同名次（竞争排名，后续顺延跳号） |
| 班排名 | 本班同方向学生内排名（若混向则按方向内子集排名） |
| 进退步 | 本次考试总分方向排名 − 上一次同方向考试总分方向排名（负数为进步；上次为"同方向上一场已导入考试"） |
| 分层 / 层 | 将方向内参考学生按总分切分为有序若干层，默认四层：优秀 / 良好 / 及格 / 待提升；名称与层数均可配置 |
| 分数线 / 线 | 层的分界分数（含"上线人数"统计用法）；每条线可"固定分数"或"按方向内人数比例自动换算"取值 |
| 科目优秀率 / 及格率 | 该科分数 ≥ 该科"优秀线 / 及格线"（默认 = 满分的 90% / 60%，可按科配置）的学生占比 |
| 低分人数 | 该科分数低于"低分线"（默认 = 满分的 40%，可按科配置）的人数 |
| 得分率 | 均分 ÷ 该科满分（用于雷达图等跨科可比指标） |
| 分数段 | 总分等距分段，默认 30 分为一档（可配 10/20/30/50/100），显示时隐藏全空段 |
| 名次段 | 方向内名次区间分段（默认 1-10/11-20/21-30/31-50/51-100/101-200/201 及以上，可配），用于考察头部集中度 |
| 参考数口径 | 见"参考学生"；所有均值/率/分层/箱线/排名类指标均只基于参考学生；学籍状态（借读等）仅作信息标注，不影响统计 |

## 3. 排名与进退步算法

1. **排名对象**：方向内（物理类全体 / 历史类全体）与班内（班级同方向子集），分别对总分行与各科行计算；
2. **排序键**：分数降序；分数相同 → 名次相同（并列），下一名次按人数顺延（1,1,3…）；
3. **不参与排名**：缺考（无行）、整场未参考（未产生总分行）；学籍状态不影响排名；
4. **进位**：保留一位小数的原始分；分数异常（>满分+1 或 <0 或非数值）在导入校验阶段拦截；
5. **进退步 move_rank（总分行）** = 本场方向排名 − 上一场（同方向、日期最近且早于本场、已导入）方向排名；上次缺考/未参考/首场 → NULL（前端显示"—"）；
6. **重算触发点**：确认导入、单条成绩修正、整场删除后；实现 = 内存排序后按 exam_id 批量 UPDATE（事务包裹，失败回滚并保留原值）。

## 4. 分层（划线）判定算法

- 分层仅针对总分（方向内）；层 i 人数 = 总分 `score >= lower_i` 且 `score < lower_{i-1}`（seq=1 层无上界；最低层下界=0）；边界**含上不含下**（`[下界, 上界)`）；
- **同分并列处理**：某生总分恰好等于层界分数时**落入高一层**（`>=` 归上层），保证"≥ 线即上线"的统计语义；
- **"X 线人数/上线"**（如"特控线上线"）即"该线对应层及以上各层的累计人数"，由层定义自然推导，无需重复存储；
- **比例换算法（ratio 模式）**：下界分数 = 方向内参考学生总分降序第 `ceil(n×ratio%)` 名的分数（同分取该档最低分，使恰为下界的都计入上层）；换算后以固定分数落库（`lower_mode='score'`），人数变化后重新"应用模板"即可按新人数重算；
- **内置模板**：① 四层：优秀(20%)/良好(60%)/及格(95%)/待提升；② 高考线：清北(3%)/985(8%)/211(20%)/特控(60%)/本科(95%)/未上线；层名可改、层可增删；
- **科目三线**（优秀/及格/低分）默认 = 满分 × 0.9 / 0.6 / 0.4，考试级 `subject_lines` 可覆盖；分层（总分）与三线（单科）相互独立。

## 5. 分析指标计算公式规范

> 除特别说明外，所有统计均遵循 **方向内可比原则**：物理类与历史类学生的分数结构不同（应考科目组合不同），排名、分层、上线与基准值都在方向内部计算。

### 5.1 基础口径

| 指标 | 定义与公式 |
|---|---|
| 学生是否参考（本场考试） | 存在总分行且 `score is not null`（至少一门应考科有分）；**不分学籍状态** |
| 参考数（班级/方向/年级） | 上述参考学生数；分母一律用参考数 |
| 科目参考数 | 该科 `score is not null` 且学生参考的行数 |
| 总分（无外部总分时） | 应考 6 科分数之和；缺考科按 0 计；某科为 NULL（非应考）不参与 |
| 均值（班/方向/年级/科目） | 参考者分数之和 ÷ 参考数 |
| 标准差 | 样本标准差 s = √(Σ(xi−x̄)²/(n−1))（n=参考数；n=1 时记为 0），Python `statistics.stdev` 口径 |
| 最高分 / 最低分 | 参考者中 max / min；科目同 |
| 优秀率 / 及格率（科目） | ≥ 该科优秀线 / 及格线（默认 90% / 60% 满分）的人数 ÷ 科目参考数 |
| 低分人数 | 该科分 < 低分线（默认 40% 满分）的人数（含 0 分参考者） |
| 与年级均值差 | 班级均值 − 方向内年级均值（方向=全部时按该班所属方向取对应年级均值） |
| 得分率 | 科目均值 ÷ 该科满分（雷达图/跨科对比用） |
| 层人数 / 层占比 | 见第 4 章 |
| 分数段 / 名次段 | 见 5.2 |
| 班排 / 方向排名 | 见第 3 章 |
| 进退步 | 见第 3 章第 5 条 |

### 5.2 分数段与名次段

- **分数段**（总分等距）：`band_width` 默认 30（可配 10/20/30/50/100）；段 = [0,30),[30,60)…直到覆盖最高分（段上限 = `ceil(max/width)*width`）；仅输出非空段；直方图与分数段同宽同界（保证图形与表一致）；
- **名次段**（方向内）：默认界 `rank_bands=[10,20,30,50,100,200,300]` → 段 [1,10],[11,20],[21,30],[31,50],[51,100],[101,200],[201,300],[301+]；界值界面可改（存 `exams.config_json`）；只统计参与方向排名的参考学生；
- 分段列标签统一：分数段 `[660,690)`；名次段 `11-20`（末段 `301+`）。

### 5.3 特殊值规则

| 场景 | 处理 |
|---|---|
| 某科应考但无分（缺考） | 不产生行、不参与该科统计与排名；明细中显示"缺考"徽标 |
| 0 分 | 有效成绩（参考者），参与均值/最低分/低分统计与排名 |
| 分数小数 | 最多保留 1 位（导入时校验提示）；排名按原值 |
| 学籍状态（借读/在籍不在校等） | 不影响任何统计与排名；明细仅显示学籍徽标作信息标注 |
| 全部科目空行 | 视为未参加本场考试，不入库（报告提示） |
| 单科超满分/负分 | 导入拦截为错误行，不落库 |
| 选科组合异常（无法推断应考科） | 按该生方向 + 主库 `subject_selection` 推断；推断失败 → 错误行提示人工修正 |

| 上次全科纯分 / 成绩排名表 | 全年级宽表 + 总分班排/方向排 + 各科班排/方向排 + 进退步 | 排名算法参照（方向内），web 排名入库、界面查询（第 3 章） |
