## 十、交互适配原则（不是功能缺失）

移动端不照搬 Excel 式操作，但**功能等价**：

| 网页做法 | 小程序做法 |
|---|---|
| 导出 Excel | 生成分享链接 / 复制数据，或提示去网页导出 |
| 打印证明 | 生成二维码，扫码核验 |
| 批量导入向导 | 保留查看与错误提示，导入动作引导到网页 |
| 宽表（全局对比/透视） | 横向滑动 + 列冻结 + 简化列 |

（本表随开发进度更新，每批次完成后勾选。）

## 十一、三页信息架构（2026-10-19）

- 首页：关键通知 → 今天/明天/后天课表（左右滑）→ 今日监考 →
  我的成绩 → 待办 → 学科成绩 / 宿舍信息 / 班级活动 / 备忘录。
- 应用：成绩管理、德育、宿舍、教务、学生画像；管理员额外「系统」；
  更多工具收纳通知、考务、总课表、查课、业绩、教师名单。
- 我的：个人信息、身份组、未读/本周监考/待办、我的课表/查课/业绩；
  环境切换与缓存清理已移出（系统页仅管理员可见）。
- 待办来自 `/api/wx/workbench` 的 `todos`，移动端只读提示去电脑端处理。
- 备忘录仅存本机；班级活动暂按校内通知关键词过滤，无则空态。
