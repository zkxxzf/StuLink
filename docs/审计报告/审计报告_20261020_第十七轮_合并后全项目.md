## 2. 已修（13 项）

### 2.1 高危

1. **Web 任课映射无年级范围**（`grades/routes/teachers.py`）
   `teachers_page/get/save` 与 `plans/use` 都用全校活跃年级，
   持 `grades.teachers` 的年级长可写外年级映射；按 R1 口径这会
   反向扩大其成绩可见范围。修法：下拉改 `visible_grades`，
   读/写/方案物化逐处 `assert_grade_visible`（与小程序同口径）。

2. **复核审批用读口径放行写**（`grades/services/review_service.py`）
   `audit_review` 的调用方（网页 / 小程序）都用 `can_view_class`，
   R1 任课教师对同年级任意班/任意科为真 → 可批准并应用改分。
   修法：服务层加第二道闸，写口径改用 `class_total_visible`
   （班主任本班 / 年级长本年级 / 校级），覆盖全部调用方。

3. **账号权限组纵向提权**（`system/routes/users.py`）
   H-01 只封了管理员组；非超管仍可把新账号授予带
   `system.grade_mgmt` / `system.users` 的组，再用页面显示的一次性
   口令登录。修法：新增 `_group_grantable`，非超管只能授予
   「权限点 ⊆ 自己」的组；`_set_user_groups` 与 Excel 导入同口径。

4. **表单文件题附件静默丢失**（`academic/routes/forms.py`）
   `question_type == 'file'` 分支 `pass`，不写 `answers_dict` →
   服务层遍历不到，`upload_file` 永不执行，附件一个都不落库，
   页面仍提示"提交成功"。修法：为 file 题建 key，让服务层走
   `files.get()` 分支。

5. **同名自动绑定越权**（`academic/services/teacher_service.py`）
   `teacher_of_user` 在同名时于 GET 请求里写库并永久绑定账号；
   `can_download` 据此判定"教师本人"→ 同名学生/家长账号请求一次
   即可拿该教师业绩附件原件。修法：加 `auto_link=False` 严格模式
   （只认 `user_id` 精确关联），鉴权路径改用严格模式。

### 2.2 中危

6. **小程序教师映射导入无范围**（`wxapi/grades/routes_manage_config.py`）
   矩阵保存已有闸，导入 `confirm` 没有 → 可写外年级映射、改角色、
   批量开户。修法：confirm 前逐行 `assert_grade_visible`，越界整批
   拒绝。

7. **整批调课只校验代表记录**（`academic/services/swap_service.py`）
   跨年级统一调课共享 `batch_id`，高一审批人可一次批掉高二的课。
   修法：`review_swap_batch` 逐条校验年级范围（只判年级，保留
   原有"对方未确认"文案）。

8. **改分/补录接受 nan/inf**（`grades/routes/exams.py`）
   `float('nan')` 能通过全部范围比较并落库，污染总分与排名。
   复核链路 10-20 已修，主改分两处漏改。修法：加 `math.isfinite`。

9. **德育/积分删除归档失败仍删**（`morality/services/reward_service.py`、
   `points/routes.py`）归档返回值被丢弃，归档抛错时记录真删、
   回收站空白。修法：任一归档返回 None 即 rollback 中止；
   奖惩删除改为返回 bool，路由据此报错。

10. **回收站恢复 0 行也标记已恢复**（`utils/trash.py`）
    主键/唯一键冲突导致全部跳过时仍写 `restored_at`，路由随后
    拒绝重试 → 实际不可恢复。修法：仅 `okn > 0` 时写并提交。

11. **通知指定年级/班级不过范围**（`notifications/routes.py`）
    只拦「全体/角色」，年级长逐个年级发一遍等于全校广播。
    修法：年级目标校验 `resolve_scope`；班级目标对班主任校验
    班级白名单。

12. **数据范围保存把"仅某班"放大为整年级**
    （`system/routes/perm_groups.py`）覆盖式 `delete()` 连班级级行
    一起删，再只写回 grade。修法：只覆盖 `class_name IS NULL` 的
    年级级行，保留精细授权。

13. **MCP 失败计数被淘汰逻辑清零**（`mcp_server/core/auth.py`）
    `_fails` 用 `(count, locked_until)`，`_prune_store` 把未锁定条的
    count 当时间戳 → 表满时整批删除，攻击者投放 1024 个键即可
    清掉自己的失败计数。修法：改 `(count, last_at, locked_until)`，
    读锁定时间改取第 3 位。

## 4. 已核实、本轮未改（下一批）

1. 复核审批「读-判-写」非原子：并发重复提交会把 delta 应用两次。
   需改 CAS（`UPDATE ... WHERE status='pending'`）或行锁，属事务改造。
2. 业绩撤销通过后与表单提交死锁：submission 仍 approved，既不能
   重交也不能重审；需状态机与幂等键一起改。
3. 旧课表 `academic/routes/timetable.py` 读写无班级范围，且页面用
   `user_grade_scope` 而非 `visible_academic_grades`（与 schedule 分叉）。
4. 业绩删除非事务：逐个附件独立 commit + 无回收站归档。
5. 表单提交可指定已结束轮次的 `round_id`（网页不传，外部可传）。
6. 课表导入草稿 token 不校验 owner（uuid 难猜，但可代为确认）。
7. 小程序学号枚举：`routes_student_profile.py` 与 MCP `find_student`
   仍是"先判存在再判范围"，404/403 可区分。
8. 小程序标准导入与 AI 导入共用 `exam.import_draft`，schema 不匹配
   时 `KeyError` → 500，且会冲掉网页待确认批次。
9. `/api/wx` JSON 信封只覆盖 403/404/500，302/400/405/413 仍回 HTML。
10. 小程序 `band-templates/save|bind` 的 `int()/float()` 未保护。
11. 令牌 TTL 配置可设 30 天，但校验端固定 12h（配置语义失效）。
12. 低危清理：`crypto.decrypt` 截断密文返回原值、
    画像首页下拉仍用全校缓存、工作记录/画像评语/积分规则删除无归档、
    通知已读进度对任意 `workbench.notifications` 开放、
    导入错误 xlsx 未走 `xl_row`、多选年级 `/api/options` 只取首个。
