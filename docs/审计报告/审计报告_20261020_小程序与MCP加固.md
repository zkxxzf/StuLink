## 1. 小程序写接口（38 条 POST/DELETE）

先确认覆盖面：`dorm/`、`workbench/`、`exam/` 三个子包**没有任何写路由**
（宿舍、考务房间在小程序里只读）；权限键逐条与网页端同功能核对，
未发现「网页用 `grades.view`、小程序降级成 `grades.student_query`」这类替换。

### 1.1 已修（5 类 9 处）

| # | 位置 | 问题 | 修复 |
|---|---|---|---|
| A1 | `grades/manage/import/confirm` | `import_token` 确认后**不作废**，同一 token 可无限重放；`mode A + remove_missing` 会反复删除"文件里没有"的学生，把别人后续录入的成绩回滚（网页端早有 P1 M-17 一次性） | commit 前 `exam.import_token = None` / `import_draft = None` |
| A2 | `auth/wechat/bind` | 只按 IP 限流（20 次/300s）→ 换出口即清零，可对同一账号无限猜口令 | 加账号级键（**不拼 IP**，10 次/300s），文案"该账号尝试过于频繁" |
| A3 | `grades/ai-import/apply`、`grades/reviews`→`review_common.exam_of`、`grades/rooms/save` | `int()` 直接包 JSON 值 → 非数字 500 | 各加 try + 参数错误信封 |
| A4 | `grades/teachers/save` | 年级取「全校活跃年级列表」，**不过数据范围** → 年级长可写外年级任课映射/建教师账号改角色 | `assert_grade_visible(grade)` + `int` 保护 |
| A5 | `academic/swap` 三条（申请/撤回/换课确认） | 整个 `wxapi/academic` 目录 `log_operation` 命中 **0** 次，网页端每条写操作都留痕 | 三处补 `log_operation` |
| A6 | 全局错误处理 | 小程序越界/不存在回 `error.html`（HTML）→ 小程序按 JSON 解析失败、界面空白 | `app/__init__.py` 的 403/404/500 对 `/api/wx` 前缀返回 JSON 信封 |

### 1.2 记录不改

- `notices/<id>/read`、`DELETE /notices/<id>`：按 `user_id` 过滤，越权不成立；
  只是对"不是我的"也回 200，与详情 404 口径不一致（低危，未改）。

## 2. MCP 服务端（只读成绩分析）

已确认**没有**的问题：不存在 `auth_mode=none` 后门（任何非 `token` 值都落
account 分支）；`require_token=false` 仍强制账号密码；令牌比对用
`hmac.compare_digest` + 非 ASCII 拒绝；工具参数无法伪造 scope；
全部 ORM（无 `text(f"...")`）；`limit` 有上限（1-100 / 1-30 / 50）。

### 2.1 已修（5 项）

| # | 位置 | 问题 | 修复 |
|---|---|---|---|
| B1 | `core/auth.py` `verify_credentials` | 停用账号返回独立 `account_disabled` + **回显用户名**，且该分支**不记失败** → 可无限探活枚举账号名 | 与"口令错"合并为 `invalid_credentials` / "账号或密码错误"，并记失败 |
| B2 | `core/auth.py` 三个计数表 | `if len(store) > MAX: store.clear()` → 攻击者用 N 个用户名/来源把表撑满，即可连自己的锁定状态一起清掉 | 新增 `_prune_store`：先删过期项，仍超容量时按插入顺序淘汰最旧一小部分 |
| B3 | `core/auth.py` | 用户名不存在时**不做 scrypt**，与"存在但口令错"有 50~150ms 差距（时间侧信道） | 新增 `_dummy_check`：对占位哈希做一次等价耗时校验 |
| B4 | `tools/scores.py` | 先 `find_student` 再 `require_student`，两者报错不同 → 持 `grades.view` 可跨年级枚举学号 | 先解析范围再查学生，两种失败统一文案（保留"无权"字样以兼容既有断言） |
| B5 | `tools/__init__.py` | 写工具判据只认 12 个动词前缀，漏 `sync_/reset_/submit_/upload_/apply_/toggle_` → 新写工具可同时绕过两道软尺子 | 前缀补到 24 个（当前 12 个工具全只读，无现存漏网） |

### 2.2 顺带修（3 项）

- `config.py`：令牌为空自动写回配置时**只按 DEFAULTS 重写**，会丢掉手加的
  `trust_forwarded_for` 等键 → 改为"已知键在前、未知键追加在后"。
- `run.py` / `tools/__init__.py` 文档仍写 R1「(年级,班级,学科) 三元组」，
  实现 10-15 已放宽为「(年级,学科) 二元组」→ 同步。
- `core/respond.py` 截断提示称"可用分页"，但 12 个工具都没有 page/offset
  → 改为"用更精确的筛选参数缩小范围"。
- `smoke_scores.py` 的 `_StubUser` 缺 `grades` 属性（多选年级改造后
  `resolve` 改读列表）→ 年级长解析成空集，既有用例失败；补齐后 89/0。

### 2.3 记录不改（部署层，非代码缺陷）

1. `run.py` 只用明文 HTTP 监听（`host=0.0.0.0`），凭据走请求头 →
   同网段可嗅探。建议：局域网内网 + 反代 TLS，或改 `127.0.0.1`。
2. `trust_forwarded_for=true` 时来源完全取自客户端自带的 `X-Forwarded-For`
   → 按来源的限流全部失效。当前默认 `false`，**不要**在没有可信反代时打开。
3. `run_stdio.py` 本地 stdio 模式认证只在启动时一次、无读频控 →
   属"本机受信用户"场景，接受。
4. `score_analysis` 的年级聚合口径（任课教师可见本年级**各科**均分）与
   R1「仅所教学科」存在解释冲突，属产品口径，未动。
5. `auth_mode=token` 的 `bind_user` 现为 `admin`（当前用 account 模式未启用）
   → 一旦切 token 模式即全校可读，切换前必须改绑只读账号。
