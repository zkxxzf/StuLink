## 五、怎么用

1. **要改某模块** → 先看最新两轮里该模块的遗留项，别把已知问题当新 bug。
2. **要修安全** → 先翻 [00-security-todo-merged.md](00-security-todo-merged.md) 的未勾选项。
3. **要写新一批修复** → 新建 `审计修复批次_YYYYMMDD.md`，写清「改了什么 → 为什么 → 怎么验 → 怎么退」。
4. **不要删除旧报告**；确认过时的，在本文档标注"仅存档"即可。
