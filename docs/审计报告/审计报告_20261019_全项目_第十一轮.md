## 1. 已修（15 项）

### P0

**A-1 排名并列实现为密集名次（1,1,2），与全系统 1,1,3 口径冲突**

- 位置：`app/modules/grades/services/ranking.py:29`（原 `rank += 1`）。
- 证据：文件头注释写「同分同名次，后延跳号」，`honor_rank.py:38`
  按位置取名次（1,1,3），只有 `_rank_map` 是分段计数。
- 影响：成绩单的方向/班排名偏小；名次段分布整段错位；进退步是两套错值之差；
  同一学生在成绩单与表彰名单名次不同。
- 修法：`rank = idx + 1`（组首位置）。历史库需重算：
  `py -3.12 scripts/fix/recalc_exam_ranks_20261019.py`（默认 dry-run，
  `--apply` 前自动备份 grades.db）。**未自动执行**，见 §4。

### P1

**A-2 班级对比「名次段」空值导致整页 500**

- 位置：`app/modules/grades/services/compare_service.py:218`。
- 证据：`rank_segment_index(None)` 内部 `low <= rank` 抛 TypeError；
  同源 `stats_service.segment_table` 有 `if not rank: continue`。
- 触发：老考试未回填排名、脚本补录后未重算。
- 修法：`if by_rank and not t.get('rank_dir'): continue`。

**A-3 小程序全局对比自建缓存不参与失效**

- 位置：`app/modules/wxapi/grades/routes_grades_compare.py`（原 `_GC_CACHE`）。
- 证据：模块内 dict + 600s TTL，不在 `invalidate_exam_cache` 任何前缀内。
- 影响：网页改分/划线/导入后，小程序最长 10 分钟仍显示旧数，两端不一致。
- 修法：改用 `cache`，键 `grades_report_ld_wxgc_<exam>_<dir>`，
  与网页共用 `grades_report_ld_` 失效前缀。

**A-4 手机号加密迁移三处漏登记（生产会漏跑）**

- 位置：`scripts/migrate/migrate_encrypt_student_phone_20261019.py`、
  `migrate_encrypt_teacher_phone_20261019.py`、
  `docs/规范与说明/数据库迁移清单.md`、`deploy/nas_migrate_pending.sh`。
- 证据：两脚本无 `_mig_log`；唯一真值清单无 10-19 条目；执行器无 run_mig。
  生产只会被 `check_columns --fix` 补出 NULL 列，按手机号精确查询全部落空，
  而页面因 `decrypt()` 兼容明文看不出异常。
- 修法：两脚本补 `_mig_log.is_applied/record`；清单登 A14/A15；
  执行器加两行 `--apply`（放在 `check_columns --fix` 之前）。

**A-5 `migration_status.py` 扫描盲区：87 个脚本只看到 1 个**

- 位置：`scripts/migration_status.py:41`。
- 证据：`scripts/migrate*.py` / `scripts/fix*.py` 是非递归 glob，
  而脚本实际在 `scripts/migrate/`（67 个）与 `scripts/fix/`（19 个）。
- 修法：PATTERNS 增加 `scripts/migrate/*.py`、`scripts/fix/*.py`，
  `_scan` 去重并跳过目录。修后输出「迁移脚本 87 个」。

**A-6 小程序登录限流可被伪造 `X-Real-IP` 绕过**

- 位置：`app/modules/wxapi/core/guards.py:28`、`auth/routes_auth.py:152`。
- 证据：无条件信任 `X-Real-IP`；账号级限流键 `login_acc_<ip>_<账号>` 含 IP，
  换 IP 即归零 → 对同一账号可无限猜口令。
- 修法：`client_ip()` 仅在 `TRUSTED_PROXIES` 命中时读转发头（默认空＝不信任）；
  账号级键去掉 IP（`login_acc_<账号>`）。

**A-7 小程序撤回/确认的 `admin` 旁路**

- 位置：`wxapi/grades/routes_reviews.py`、`wxapi/academic/routes_swap.py`。
- 证据：撤回允许 `role == 'admin'` 代撤他人复核单；对方确认允许 admin 代确认，
  而服务层 docstring 的前提是「路由层已校验 partner 本人」。
- 修法：两处都收紧为仅本人 / partner 本人；管理员走网页审批链路。

**A-8 无教师档案账号可用 `username` 冒充 `teacher_uid`**

- 位置：`wxapi/academic/swap_common.py:13`。
- 证据：无 Teacher 档案时回落 `username[:16]`，`teacher_uid` 也是 String(16)，
  同名账号可看到并以对方身份发起/确认调课。
- 修法：无档案返回 `(None, name)`，调用方按空集 fail-closed。

## 3. 未修 / 待拍板（下一轮）

1. **时间表自动保存无幂等键**：响应丢失/多标签页会在 `affair_schedules`
   插入重复场次（无唯一约束）→ 监考格与工作量翻倍。建议加
   `UniqueConstraint(affair_id, exam_date, start_time, subject)` + upsert。
2. **改场次时间不失效已排监考**：改完时间后可能出现「一人同时监两场」，
   系统不提示。建议保存时标记待校验或自动检测冲突。
3. **小程序批量下发逐生总分**：honor / 学生档案 JSON 含 `total` 与全科分。
   与网页端公开口径一致，但 JSON 比 HTML 更易批量抓取——**需用户拍板**
   是否在小程序侧只给名次。
4. **小程序分析接口未复用 `grades_tab_` 缓存**：每次切页签全量重算
   （网页端 900s 缓存）。
5. **性能**：`best_assign` 的 tries 只看格数不看教师池规模；
   `scores_of_subject` 每次遍历全场；名次段「年级合计」含非教学班学生。
6. **同名校验**：监考池按姓名去重，同名教师只会排到一人。
7. **B 组迁移仍有 50 个「人工核对」**（无 `_mig_log` 或无法自动判定），
   建议后续按批次补齐。

```powershell
py -3.12 scripts/fix/recalc_exam_ranks_20261019.py          # 预览会变多少行
```

注意：重算会改变已发布成绩单的名次（同分并列越多，变化越大）。
