## 2. 结论摘要

三条主风险链：

1. **边界失守**：全站明文 HTTP + `0.0.0.0` 直连 + MCP 暴露，口令/Session 可嗅探。
2. **一失全失**：密钥、`.env`、密文、明文整库备份同处一个同步目录。
3. **内控可绕过**：权限组可提权、复核/调课可自审自批、考务可越权删人且无痕。
