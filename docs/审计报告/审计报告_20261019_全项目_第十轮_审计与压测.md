## 三、修复项

### F1（高，前端）学期「激活」确认框失效

- 文件：`app/templates/academic/schedule_manage.html`。
- 现象：`onsubmit` 里的 `|tojson` 只作用于最后一段拼接串，渲染成
  `confirm(激活「X」？"当前…")`，浏览器报
  `missing ) after argument list`；确认框不弹，表单可能直接提交。
- 修复：把**整段拼接串**加括号后再 `|tojson`。
- 验证：渲染 HTML 中 3 个 `confirm` 全部是 `confirm("…")`；
  单页点击复跑 0 异常。

### F2（高，安全）微信扫码登录 `/qr/consume` 的 CSRF 豁免

- 文件：`app/modules/auth/wechat_routes.py`、`auth/qr_login.html`。
- 现象：`@csrf.exempt` 让安全扫描长期红项（372/1）；
  二维码 ticket 虽有会话绑定，但少一道 CSRF 防线。
- 修复：去掉豁免；页面带 `QR_CSRF` 并在 POST 头里发 `X-CSRFToken`。
- 验证：`/qr-login` 有 token；无 token POST → 400；
  带 token 但伪 ticket → 403；安全扫描 **0 命中**，安全回归 **373/0**。

### F3（中，权限 UI）学生搜索页「导出」教师可见但 403

- 文件：`app/templates/system/students/search.html`。
- 现象：导出链接不判 `students.export`，教师点击 403；
  同时 `#checkAllSearch`/`#btnBatchEditSearch` 对无编辑权限者不渲染，
  脚本直接 `addEventListener` 触发空指针。
- 修复：导出链接加权限包裹；全选与批量按钮加空值保护。
- 验证：教师页导出链接 0 个、JS 错误 0、批量按钮不显示；
  管理员导出入口保留；全量回归仍全绿。

### F4（测试夹具，不是产品 bug）课时量用例串号

- 文件：`tests/academic_regression.py::WORKLOAD`。
- 现象：查课用例把 `01班` 当天第 2 节登记在 `T900001` 名下，课时量
  用例却用 `T900002` 断言「总课时 == 0.5」→ 实际 `1.5` 或 `1.0`。
- 修复：课时量用例改用独立 `T_WL_QA`，结束时还原原任课人；
  断言按实际节次现算。教务回归 **655/2 → 657/0**。
