## 3. 复核剔除的误报（重要）

| 静态结论 | 复核方式 | 结论 |
|---|---|---|
| `$('#scoreModal').modal('show')` 在 BS5 上必抛 TypeError，改分弹窗打不开（被判"高"） | 真实 Edge 加载仓库自带 `jquery-3.7.1` + `bootstrap.bundle`（5.3.3），探针输出 `fn_modal=function`、`modal('show')` 后 `show` 类存在、无 pageerror | **误报**：BS5 仍注册 `$.fn.modal` 兼容接口（`defineJQueryPlugin`）。`tests/_archive/qa_20261019_audit13/verify_modal_api.py` 可复跑 |
| `assign_auto.html` 同类 API 导致自动分宿舍卡死 | 同上 | **误报** |
| `morality/rewards.html` 保存后不刷新 | 同上 | **误报** |

> 教训（已第 3 次）：前端 API 兼容性不能只按版本号推断，必须真机跑；
> 版本号相同的 bundle 里可能保留了旧接口。

   `add_approval` 写 JSON 列再 commit，无乐观锁 → 双审/双击丢失审批记录。

### 5.3 P2（性能，需单独验证后上）

1. `ExamData` 冷构建在**全局锁**内、无单飞：16 线程同时打开分析页最坏串行
   16×0.3~0.8s；`rows` 仍是全场 ORM。建议按 exam_id 单飞 + `load_only`。
2. `scores_of_subject` 每次 O(全场)，按班取应预分组 `(班,科)`；`teacher_tab`
   每 link 4 次全扫（180~300 link → 百万级内层循环）。
3. `grade_context`（AI/MCP）逐班逐科重算，一次报告 10~30 次工具调用反复全扫。
4. 导出接口直接调 `*_tab()`，绕过 900s 缓存；导入是单事务长写锁（非 WAL，
   库级锁 3~15s）。
5. `operation_logs.target_type` 无索引；回收站清理把全部命中行（含 payload）读入内存。
