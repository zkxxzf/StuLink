# StuLink 成绩管理 · 帮助文档（流程详解）

> 适用版本：v1.9.2（2026-09-16）　｜　配套：`成绩管理操作手册.md`（界面操作）
> 本文档**只讲流程**：每一步做什么、走到哪、会触发什么、出错了怎么办。用文字流程图串起各功能。

---

## 0. 全景数据流

```
┌─────────────┐   ┌──────────────┐   ┌────────────┐   ┌──────────────┐   ┌──────────┐
│ ① 新建考试  │──>│ ② 导入成绩    │──>│ ③ 重算排名  │──>│ ④ 划线分层    │──>│ ⑤ 分析展示 │
│ (exam 主档) │   │ (exam_scores) │   │ (rank_dir  │   │ (exam_bands)  │   │ 四 tab    │
│             │   │              │   │  /move_rank)│   │              │   │ 导出/打印 │
└─────────────┘   └──────────────┘   └────────────┘   └──────────────┘   └──────────┘
      │                │                                                  │
      └────────────────┴──────── 任课教师映射（独立维护，供「任课教师」tab 用）────┘
                           操作日志(OperationLog) 记录每次 新建/导入/重算/删考试/划线/导出
```

依赖顺序：**①→②→③ 是强序**（没考试不能导入；没导入不能重算/分析）。**④ 划线** 在分析之前做才有分层图；不做也能看基础表。**任课教师映射** 与 ①②③ 平行，但要在看「任课教师」tab 前维护好。

## 1. 新建考试流程

```
考试管理 → 新建考试
   ├─ 填：年级(必选) / 考试名称(必填) / 考试日期 / 考试类型
   ├─ 校验：年级+名称 都不能空  → 否 → 退回重填
   ├─ 查重：同年级同名考试已存在？ → 是 → 拦截（提示修改名称，避免成绩分散）
   └─ 通过 → 写 exams 表(status=draft) → 记日志 → 跳转考试详情
```

关键点：
- 同名考试被**阻断**（非仅警告），防止两场同名考试混淆统计。
- 考试日期决定「历次考试」排序与折线图 X 轴。
- 新建后状态为 `未导入`，必须先导入成绩才能分析。

## 2. 成绩导入流程（最核心）

### 2.1 总流程

```
考试详情 → 导入成绩
   ├─ 选 Excel 文件
   ├─ 选模式：A 增量覆盖(默认) / B 整场重置
   │     └─ 模式 A 可勾「一并移除本次文件中未出现的原有学生成绩」(慎用)
   ├─ 点「解析并预览差异」
   │     ├─ 解析失败(非标准模板/损坏) → 报错退回，建议下载模板
   │     └─ 解析成功 → 生成 import_token + import_draft(JSON 暂存，不落成绩库)
   ├─ 展示预检报告（识别结果 + 7 张统计卡 + 错误行）
   ├─ 核对差异（新增/更新/删除/未出现保留是否符合预期）
   │     ├─ 有错误 → 可下载错误明细 → 改文件 → 「修改文件重新上传」重来
   │     └─ 无误/可接受 → 点「确认导入」
   └─ 确认(二次弹窗) → 事务写入 → 整场重算排名 → status=imported → 记日志 → 回考试详情
```

### 2.2 两种导入模式差异（决定哪些数据被改写）

```
模式 A 增量覆盖（推荐，日常）
   影响范围 = 文件出现的(学生 × 科目列)
   ├─ 单元格有分      → upsert 覆盖旧值
   ├─ 该科列空        → 删旧行(视为本次缺考)
   ├─ 文件未出现的科目 → 保留旧值（下次补导其他科互不影响）
   └─ 文件未出现的学生 → 默认保留（勾选 remove_missing 才一并删除）
   报告：新增 X / 更新 Y / 删除 K(缺考) / 未出现保留 P

模式 B 整场重置（纠错）
   先清空本场全部成绩行 → 再只按本次文件导入
   适用：上次整体导错、要彻底重来
```

### 2.3 解析与校验规则（决定哪些行进错误报告）

```
逐行解析：
   ├─ 表头识别失败 / 缺「学号」列        → 直接报错（引导下载模板）
   ├─ 含「总分」列 → 模板 A；否则 → 模板 B
   ├─ 年级列有值且与考试年级不一致       → 该行错误（防跨年级混入）
   ├─ 学号匹配不到主库学生              → 该行错误
   ├─ 分数 非数值 / <0 / >满分+0.5       → 该行错误（不落库）
   ├─ 非应考科目（如历史类填了物理）      → 忽略该格（不报错）
   ├─ 整行全空                         → 不计（提示未参加）
   └─ 借读/在籍不在校                    → 不剔除、不报错（仅统计页徽标标注）
错误行全部跳过，不阻断整批；可下载 xlsx 改后重传。
```

### 2.4 确认导入后系统做了什么

```
确认导入(事务)：
   1. 按模式合并写入 exam_scores（快照 年级/班级/方向/选科/姓名）
   2. ranking.recalc_exam() 整场重算：
        - 方向内排名 rank_dir、班内排名 rank_class
        - 进退步 move_rank = 本次方向排 − 上次同方向考试方向排
   3. exam.status = imported，写 import_info（文件名/模式/摘要/操作人/时间）
   4. 清该考试分析缓存 tab_service.clear_exam_cache()
   5. 记 OperationLog（模块=grades）
   失败 → 回滚，提示「导入失败，数据已回滚」
```

> 分批补导（先导语数外、下次补导其他科）走模式 A 即可，未出现的科目不被改动。

## 3. 单条修正 / 重算流程

```
考试详情 → 某成绩格「编辑」
   ├─ 填新分 → 写回该行
   │     └─ 单科改分 → 自动重算该生总分行（直接改总分行则不重算，保留手工值）
   ├─ 清空 → 删该行(视为缺考) → 自动重算该生总分行
   └─ 改完 → exam.status = dirty（待重算）→ 提示「请点重新计算排名」

考试详情 → 重新计算排名
   └─ recalc_exam() 全量重排 → status=imported → 清缓存 → 记日志
```

注意：**单条改分后必须点「重新计算排名」**，否则排名/进退步是旧的。整场确认导入会自动重算，无需手动。

## 4. 删除考试流程

```
考试详情 → 删除考试
   ├─ 输入考试名称二次确认（防误删）
   │     └─ 名称不一致 → 拦截
   └─ 通过 → 删 exam_scores + exam（级联）+ 清缓存 → 记日志 → 回考试列表
```

不可恢复，删除前建议备份 `grades.db`。

## 5. 划线分层配置流程

```
考试详情 → 划线分层（grades.settings 权限）
   ├─ 选：下界方式(固定分数/人数比例%) / 录入形态(分科/全科统一) / 含总分
   ├─ 快速填层名：四层 / 高考线（只填层名）
   ├─ 在格子填各层下界值
   │     └─ 切「分数/比例」→ 已填值清空（弹确认，因含义不同）
   ├─ 点「保存划线」
   │     ├─ 前端预校验：层名非空 / 同层下界递减 / 比例 0–100 / 非负
   │     │     └─ 不通过 → 列出全部问题，不提交
   │     └─ 通过 → POST /api/bands/batch → 写库 + 清缓存 → 提示「已保存」
   └─ 页面回填（load 读回已存划线，确认保存生效）
```

规则：
- 行=层（第 1 层最高），列=科目；选科后按 物理类/历史类 分两组列，可填不同线。
- 同一层内下界必须**从高到低**。
- 留空的格子不划线，也不动已有设置。
- `人数比例%` 模式下，分数由系统按该组该科排名自动换算（比例换算法：下界=降序第 ceil(n×比例%) 名的分数）。

## 6. 成绩分析加载流程（前端视角）

```
进入「成绩分析」
   └─ GET /grades/api/options
        ├─ 返回：可见年级 / 各年级考试 / 班级 / 科目 / 可见 tab / 锁定范围
        ├─ 隐藏无权 tab（如班主任看不到年级/学科/教师 tab）
        ├─ 默认选中第一个可见 tab + 最近一场 imported 考试
        └─ activateTab(first) → 加载该 tab

切换 tab / 改筛选（年级·考试·方向·班级·科目）
   └─ loadCurrent()
        ├─ 显 loading 态
        ├─ GET /grades/api/analysis/<tab>?exam_id=...&...
        │     ├─ 服务端先过 scope 白名单（越界 → 403，前端显「无权查看」）
        │     ├─ 无数据/空场 → meta.empty → 显空态引导
        │     └─ 成功 → 渲染表格(可折叠) + ECharts 图表
        └─ 切回「班级分析」时从班级下拉还原 state.class_name（否则返回后班级数据为空）

筛选器显隐（由 tab 决定）：
   年级分析：方向可见、班级隐藏、科目隐藏
   班级分析：方向隐藏、班级可见、科目隐藏
   学科分析：方向可见、班级隐藏、科目可见
   任课教师：方向隐藏、班级隐藏、科目可见(含「全部科目」)
```

导出：`GET /grades/export/<tab>?<同筛选>` → openpyxl 生成多 sheet xlsx（表格数据，不含图）。
打印：`window.print()` → 仅当前激活 tab，打印样式隐藏菜单/工具栏。

## 7. 任课教师映射维护流程

### 7.1 网页矩阵

```
任课教师映射 → 选年级
   └─ GET /grades/api/teachers?grade= → 渲染矩阵(科目×班级)
        ├─ 单元格下拉选教师（仅已启用账号）
        ├─ 整行设为：某科目所有班设同一教师
        ├─ 整列填充：该班所有科设同一教师（输入姓名/账号）
        └─ 保存全部 → POST /api/teachers/save
              └─ 预览「绑定 N / 变更 M / 停用 K」→ 生效
```

### 7.2 批量导入（同构《教师安排表》）

```
批量导入教师安排表
   ├─ 上传 xlsx（可含多年级分段；英语→外语别名；忽略非高考科目/正副班/教室等列）
   ├─ 逐 (年级,班,科) 按姓名核对账号：
   │     ├─ 命中启用账号   → 绑定（旧映射停用）
   │     ├─ 账号停用/重名  → 错误行
   │     └─ 无账号         → 自动开户（real_name 固定、账号=拼音、随机初始密码、强制改密）
   ├─ 预览开户清单（密码仅此一次可见，可下载《账号开通清单》）
   └─ 确认 → 建号 + 写映射 → A4 分析即时生效
```

注意：教师 `real_name` 不可改（身份锚）；`username` 可改（如改手机号），不影响映射。

## 8. AI 分析流程（可选）

```
成绩分析 → 选好考试 → 点「AI 分析」
   ├─ GET /grades/ai/scope?exam_id= → 算发送范围/人数/上次对比考试/可用 Key
   ├─ 无 Key？
   │     └─ 弹窗引导填个人 Key（或联系管理员配公共 Key）→ 保存 → 重新预览
   ├─ 有 Key → 弹「发送确认」：
   │     展示 本次考试 / 对比考试 / 发送范围 / 学生人数 / 使用密钥
   │     ⚠ 提示：成绩数据将发往 AI 服务商，离开学校内网
   ├─ 点「生成 AI 报告」（约 30–90 秒）
   │     ├─ 服务端 build_payload（仅本人有权数据）+ call_llm
   │     ├─ 成功 → 写 AiReport（本人；admin 看全部）→ 报告渲染到当前 tab 顶部
   │     └─ 失败(无 Key/无数据/调用异常) → 报错提示
   └─ 报告可复制/关闭；「AI 报告」菜单看历史（可按考试筛选、删除）
```

Key 来源优先级：**个人 Key > 管理员公共 Key**。Key 加密存储，仅本人（或管理员看公共 Key）可见。

## 9. 异常与回退汇总

| 现象 | 流程位置 | 处理 |
|---|---|---|
| 同名考试建不了 | 新建 | 改考试名称 |
| 整批导入报错 | 解析 | 下载模板，核对表头/学号列 |
| 部分行进错误报告 | 解析校验 | 下错误明细 xlsx 改后重传（错误行不落库） |
| 误覆盖/旧行残留 | 模式 A 差异预览 | 确认前核对「更新/删除/未出现保留」；必要时用模式 B 重置 |
| 排名/进退步旧 | 单条改分后 | 点「重新计算排名」 |
| 分层图不显示 | 分析前 | 先到考试详情做划线分层 |
| 分析页空白/下拉空 | 缓存/无 imported 考试 | Ctrl+F5 强刷；确认有已导入考试 |
| 保存划线「页面过期」 | CSRF 失效 | 刷新页面（Ctrl+F5）重试 |
