# 课表导入模板说明（2026-10-10）

本文说明「学期课表 → 课表导入」支持的**表格版式、字段规范、校验规则与错误提示**。
模板可以直接从导入页下载，无需手工搭建。

- 入口：`学期课表管理 → 导入课表`，即 `/academic/schedule/<sid>/smart-import`
  （页面右上角有「全校总课表模板 / 整班矩阵模板 / 空白模板」下载按钮）
- 命令行：`python scripts/import_school_timetable.py --file "D:/课表.xlsx"`
  （与网页共用同一套解析与写入逻辑，适合整校批量灌数据）

---

## 1. 支持的导入格式

| 项目 | 支持情况 | 说明 |
|---|---|---|
| `.xlsx` | ✅ 原生支持 | Excel 2007+，推荐 |
| `.xlsm` | ✅ 原生支持 | 带宏的工作簿，宏不会执行，只读数据 |
| `.xls` | ❌ 不支持 | 请用 Excel「另存为 → Excel 工作簿(.xlsx)」 |
| `.csv` | ❌ 不支持 | 课表是二维矩阵，CSV 表达不了合并单元格；请另存为 `.xlsx` |
| 多 sheet | ✅ | 每个 sheet 独立识别版式，可一次上传整校课表 |
| 空 sheet | ✅ 忽略 | 模板自带的空白 `Sheet2/Sheet3` 不会报错 |
| 单元格公式 | ⚠️ 取计算结果 | 用 `data_only` 读取；若公式未算过（无缓存值）会读成空 |

> 合并单元格：**A 列的星期可以合并**（当天只写一次，系统向下继承）；
> 其它位置请不要合并，合并会丢内容。

---

## 2. 两种版式（自动识别，不用手选）

### 形态 ① 全校总课表 —— 一张表放全校（推荐，学校最常用）

行 = 星期 × 节次，列 = 班级，每列一个班。

```
┌──────┬──────┬────────┬────────┬────────┐
│ 星期 │ 节次 │ 高三1班 │ 高三2班 │ 高三3班 │   ← 第 1 行是表头
├──────┼──────┼────────┼────────┼────────┤
│星期一│  1节 │ 历史   │ 英语   │ 英语   │
│      │      │ 郭艳静 │ 王一楠 │ 任润萌 │   ← 格内第 2 行写教师（可省略）
│      │  2节 │ 语文   │ 语文   │ 物理   │
│      │  3节 │ 地理   │ 政治   │ 语文   │
├──────┼──────┼────────┼────────┼────────┤
│星期二│  1节 │ 英语   │ 语文   │ 数学   │
│      │  2节 │ 语文   │ 数学   │ 数学   │
└──────┴──────┴────────┴────────┴────────┘
```

- 一个班一列；增减班级就是加减列，结构不用动。
- 只排到周五就只写到周五；有周六/周日再补行。

### 形态 ② 整班矩阵 —— 一个 sheet 一个班

行 = 节次，列 = 周一~周五，sheet 名（或表格上方标题）写班级。

```
        高三1班 课表
┌────────┬──────┬──────┬──────┐
│  节次  │ 周一 │ 周二 │ 周三 │
├────────┼──────┼──────┼──────┤
│  早读  │ 语文 │ 英语 │ 语文 │
│  第1节 │ 数学 │ 语文 │ 数学 │
│        │ 张伟 │ 李娜 │ 张伟 │
└────────┴──────┴──────┴──────┘
```

## 3. 字段规范

「字段」在矩阵模板里对应**表头 / 行标签 / 格内内容**三个位置。下表是完整的对照关系。

| # | 模板中的位置 | 系统字段 | 数据类型与格式 | 必填 | 示例 | 校验与容错 |
|---|---|---|---|---|---|---|
| 1 | 形态①表头 C 列起<br>形态②sheet 名或上方标题 | `grade` + `class_name` | 文本，年级 + 数字班号，≤12 字 | **必填** | `高三1班`、`2024级01班`、`高三(1)班`、`01班` | 年级会自动与学期年级对齐（`高三`→`2024级`）；识别不出年级时按原文记录。**同一列/同一个 sheet 只能是一个班** |
| 2 | A 列（形态①）/ 表头行（形态②） | `weekday`（星期） | 文本：`星期一`~`星期日`，或 `周一`/`礼拜一`/`1`~`7` | **必填** | `星期一` | 形态①的 A 列**可合并**（当天写一次即可，向下继承）；识别不到星期的行会被跳过 |
| 3 | B 列（形态①）/ 首列（形态②） | `period_number`（节次） | 文本：`1节`/`第1节`/`早读`/`晚自习1` | **必填** | `1节` | 优先按学期「节次配置」里的**名称**匹配，`N节` 自动对应「第N节」；名称对不上→该行跳过并提示（见 §5） |
| 4 | 格子第 1 行 | `subject`（学科） | 文本，≤20 字 | **必填** | `语文`、`数`、`生物学考` | 支持简写与考试类型后缀（详见 §4）；完全认不出的按原文入库并列入「未识别学科」 |
| 5 | 格子第 2 行 | `teacher_name`（教师） | 文本，≤50 字 | 选填 | `郭艳静`、`张老师` | 按姓名自动匹配教师名单；匹配不上按原文记录，只提示不报错 |
| 6 | 格内 `(单周)` / `(双周)` / `(3-5)` | `week_range`（周次） | 文本：`单周`/`双周`/`1-9`/`5` | 选填 | `语文(单周)` | 不写 = 用导入页「整批周次」；都不填则默认 `1-18`。**单双周必须写在格子里**，系统才能两门课共用同一时段 |
| 7 | 格内 `@301` 或 `（301）` | `room`（教室） | 文本，≤30 字 | 选填 | `物理@实验室2` | 教室为空表示"在本班教室" |
| 8 | —（不来自表格） | `teaching_class`（走班教学班） | 文本，≤30 字 | 选填 | `物化生1` | 行政班课留空；分层/走班课才填。**并行课（两科同时上）必须用这个，不能写在同一格** |
| 9 | 格子第 1 行（多段） | 多条目 | 一格多行 = 多条课 | — | `地/政` + `陈/邓` | 一格内写多科会拆成多条；若不是单双周标注，写入时同班同时段只保留第一条（见 §5） |

> 说明：本系统**不单独存"课程代码"**——学科名本身就是主键口径（`语文`、`数学`…），
> 目的是让课表、任课映射、成绩模块用同一套学科字符串对齐。
> 若学校有 `YW-2024-01` 这类代码，请在导入前替换成学科名（或联系开发增加映射表）。

### 常见课表信息 → 本系统怎么表达

| 学校课表里的列 | 本系统 |
|---|---|
| 课程名称 | 格子第 1 行 → `subject`（学科） |
| 任课教师 | 格子第 2 行 → `teacher_name`（自动匹配教师名单） |
| 星期 | A 列（形态①）/ 表头行（形态②） → `weekday` |
| 节次 | B 列（形态①）/ 首列（形态②） → `period_number` |
| **上课时间（几点几分）** | 由学期「节次配置」统一定义（如 `第1节 08:00-08:45`），**不在表格里逐格写**；要用学校自己的作息，先去「节次配置」改 |
| 上课地点（教室） | 格子内 `@301` → `room` |
| 周次 / 单双周 | 格内 `(单周)`/`(双周)`/`(1-9)` → `week_range` |
| 课程代码 | 不单独存（用学科名） |

## 4. 学科与节次的写法（容错范围）

**学科**（自动归一）

- 全称与常见简写：`语`/`语文`、`数`/`数学`、`英`/`外语`/`英语`、`物`、`化`、`生`、`政`/`思想政治`/`思品`、`史`、`地`、`体`、`音`、`美`、`信`/`信息`、`通用技术`、`劳技`、`班`/`班会`/`德育`、`自`/`自习`、`晚自习`、`早读`/`晨读`、`心理`、`社团`、`升旗`、`大课间`
- 带考试/课程类型后缀会自动取本体：`生物学考` → `生物`、`语文选考` → `语文`、`数学必修` → `数学`
- 认不出的（如 `日语`、`生涯规划`）**照原文入库**，并在预览里列为「未识别学科」供人工确认

**节次**

- 与学期「节次配置」的名称对得上即可；`1节`/`第1节`/`第一节` 都会映射到系统的「第1节」
- 「早读」「晚自习1」这类按名称匹配
- **对不上 = 该行整行跳过**（最高频的"掉内容"原因）：例如表格写 `第9节`，
  而学期只配到 `第8节` → 请先在「节次配置」里补齐第9节，或把表格改成已有名称

**空值**：`—` `-` `/` `\` `无` `空` `休息` `.` `TBD` 都当作"没课"。

## 5. 校验规则与错误提示

导入分两步：**解析预览（不写库）→ 确认写入**。所有问题都在预览里先暴露，避免"导完才发现错"。

### A. 解析阶段（预览页）

| 现象 | 提示位置 | 处理方式 |
|---|---|---|
| 找不到可识别的表头 | 预览页「以下表被跳过」 | 整张 sheet 跳过，其它 sheet 继续 |
| 节次对不上学期作息 | 每班「警告」列表 | 该行跳过并点名"第 N 行有内容但节次未识别" |
| 教师不在教师名单 | 每班「警告」列表 | **不阻断**，按姓名原样入库（`teacher_uid` 为空 → 教师维度课表里查不到这个人） |
| 一格写了多门课 | 每班「警告」列表 | 拆成多条；提示"若非单双周请改用走班教学班" |
| 同一班同一时段写了两门课 | 每班「警告」列表 | 后续写入时第二条会被跳过 |
| 学科认不出 | 「未识别学科」清单 | 照原文入库，人工确认 |

### B. 写入阶段（确认导入后）

| 冲突类型 | 提示 | 行为 |
|---|---|---|
| 班级冲突（同班同时段已有课，且周次有交集） | `班级冲突：2024级03班 周一第5节 已有「地理」` | **跳过该条**，其余继续 |
| 教师冲突（同教师同时段，且周次有交集） | `教师冲突：张伟 周一第5节 已有「数学」` | 跳过该条 |
| 周次无交集（如单周 vs 双周） | 无 | **不算冲突**，两条共存 |
| 整批完全为空 | `没有解析到任何课程` | 不写库，留在导入页 |

> 写入是**追加**，不会清空已有课表。重复导入前建议先看「全校总课表」，或命令行用 `--replace`。

### C. 命令行版的报告

```
[学期] id=4 2026-2027学年第一学期（课表导入） status=draft（新建）
[节次] 13 节：早读、第1节、…、晚自习3
[解析] 班级 30 个 · 课表条目 1290 条
[校验] 警告统计：教师未匹配 1104 处、一格多科 10 处
[明细] 班级 → 条目数 …
[写入] 成功 1280 条，跳过 10 条
  ! 第 95 条：班级冲突：2024级03班 周一第5节 已有「地理」
```

## 6. 操作步骤

**网页**

1. `学期课表管理` → 选目标学期 → `导入课表`
2. 右上角下载模板：**全校总课表模板**（列=班级，适合整校）/ **整班矩阵模板**（一个 sheet 一个班）/ 空白模板
3. 「整批周次」可选：按周次为单位批量导入时填 `5` / `1-9` / `单周`；留空按格内标注（缺省 1-18）
4. 上传 → 看预览（逐班条目 + 矩阵预览 + 警告）→ 需要时在预览里改班级 → `确认导入`

**命令行**

```bash
# 干跑（只报告，不写库）
python scripts/import_school_timetable.py --file "D:/课表.xlsx"

# 正式导入到新建学期，并设为启用中 / 当前学期
python scripts/import_school_timetable.py --file "D:/课表.xlsx" --commit --activate

# 导入到已有学期；整批周次；先清空旧课表
python scripts/import_school_timetable.py --file "D:/课表.xlsx" \
    --term-id 5 --week 1-18 --replace --commit
```

## 7. 常见问题

**Q：导入后有人只显示学科、没有教师？**
教师列留空了，或姓名与教师名单不一致（会在预览里提示）。到
`教师名单` 里核对姓名，或在课表里手工补。

**Q：为什么有的课没导进来？**
按出现频率：① 节次名称与「节次配置」不一致（最高频）② 同班同时段已有一条（冲突跳过）
③ 学科/教师写在了意料之外的位置。预览页的警告列表会点名到"第几节周几"。

**Q：一格里的「地/政  陈/邓」怎么处理？**
会当成两条：`地理·陈` + `政治·邓`。若这两门课是**单双周交替**，请改写成
`地理(单周)/陈` 与 `政治(双周)/邓`（两行也可）；若是**同时上**的分层/走班课，
请用「走班教学班」表达，别写在同一格——否则第二条会被当成班级冲突跳过。

**Q：上课时间（几点几分）在哪里改？**
不在课表里改，去 `节次配置`（`/academic/schedule/<sid>/periods`）：那里同时定义了
节次名称、起止时间与类型（早读/上午/下午/晚自习），并且页面下方就是「作息时间表」
视图，可直接 A4 打印。
