## 1. 方法

工具：`tests/_archive/qa_20261015/tap_all.py`（Playwright + msedge 无头，点击沙箱 5098 独立数据副本）。

1. **会话**：用真实账号按角色签发 cookie 注入浏览器。⚠ 关键坑：Flask-Login 的 `_id`
   由 `remote_addr | User-Agent` 算出 —— 必须用**浏览器真实 UA** 签发，否则被判会话劫持、
   整页退回登录页（首次试跑就踩到：三页都只拿到登录页 7730 字节）。
2. **页面池**：先用真实账号扫全部 137 个无参 GET 页面，按**返回内容**剔除「被重定向到
   修改密码页」的假可用（真实库里 93 个账号处于 `must_change_pwd=1`）。
3. **逐页穷举**：枚举页面上所有可交互元素并**逐个真点** ——
   `[data-bs-toggle]`（弹窗/下拉/折叠/标签）、`button`、`a.btn`、`.dropdown-item`、
   `select`（真选值触发 change 联动）、`[role=tab]`、`checkbox/radio`（点开再恢复）、`[onclick]`；
   点击前 `scroll_into_view_if_needed`，被遮挡时记录并强制点一次（区分"可见性问题"与"点了没反应"）。
4. **每次点击后**：等待、比较弹层状态（modal/dropdown/collapse/offcanvas/tooltip/popover），
   有变化即**截图**；关闭弹层并断言**无孤儿 backdrop**、无"弹窗关不掉"。
5. **收集**：`pageerror`、`console.error`、HTTP ≥400、请求失败；所有 `confirm` 一律**取消**
   （按钮被点到、数据不被删）。

## 2. 发现并修复：属性引号截断（22 处，真 bug）

**根因**：`属性="…{{ x|tojson }}…"` —— Flask 的 `|tojson` 输出**带双引号**的 JSON 字符串，
直接把双引号属性的值**截断**：

- 事件属性（onclick/onsubmit）：内联脚本只剩半句 → 浏览器报 **`Unexpected end of input`**，
  按钮/卡片**点了完全没反应**（以下 9 处，用户天天点）：
  班级概览卡片链、学生列表「调班」、通知卡片、年级管理「毕业」、考务批次「删除」、
  宿舍房间卡片、床位「移除」（两处）、证书「作废」、字典删除确认；
- `data-*` 属性：值被截断 → JS 读到空/残值，**功能静默失效**（评语编辑 3 个属性、
  课表 `data-kw`、调课 `data-entry`）。

**修复**：属性外层改**单引号**（`onclick='f({{ x|tojson }})'`、`data-x='{{ x|tojson }}'`）——
`|tojson` 会把 `'` 转义成 `\u0027`，防注入口径不变。

## 4. 守卫固化（防回退）

1. **`scripts/check_frontend_compat.py` 新增第 5 条规则**：
   属性双引号 + `| tojson`（含 `| tojson` 带空格的写法）即失败，并提示改法。
   —— 该规则上线后立刻又抓出 6 处漏网（课表学期操作）。
2. **`tests/sec_regression.py` H-10 口径更新**：原断言写死 `data-x="{{ …|tojson }}"`（双引号），
   而该写法本身会被截断 → 改为断言单引号形式（防注入本质不变：`|tojson` + 事件委托 + `JSON.parse` 都在）。
3. 回归基线：教务 **628** / 安全 **371**（仅 H-9 环境项）/ 宿舍 71 / 班级 8 / smoke 8 组全绿。
