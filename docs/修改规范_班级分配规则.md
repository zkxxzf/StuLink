# 班级分配规则修改规范

> 创建日期：2026-07-19
> 适用文件：`app/modules/dormitory/services/room_assignment_v4.py`
> 用户需求：3 条规则修改

## 一、需求分析

### 规则1：班级按班号从小到大排序（不按人数多寡）

**当前行为**：`_build_grade_aware_class_order` 已按 `(年级, 班型, 班号)` 排序
- 排序键：`(grade_year, type_priority, class_num)`
- 班型优先级：强基班=0, 卓越班=1, 其他=2
- **问题**：班型聚集导致同年级内强基班先排，卓越班后排

**用户要求**：班级按 01班→10班 从小到大排列，不需要优先编排住校生多的班级

**修复方案**：
- 简化排序键为 `(grade_year, class_num)`
- 去掉班型聚集逻辑（强基班/卓越班不再优先排）
- 保留年级升序（老生优先）

### 规则2：合班宿舍至少挨着其中一个班级

**当前行为**：`_pick_combine_room` 函数
- 优先级1：在两个班级房间段之间找空房
- 优先级2：离两班边界距离之和最小的空房
- 兜底：取剩余房间的中间位置（**问题所在**）

**问题**：当优先级1和2都失败时，兜底取"剩余房间的中间"，可能位于所有班级之后

**修复方案**：
- 修改兜底逻辑：找离任一合班班级最近的空房（而非剩余房间的中间）
- 具体实现：计算每个空房到两个班级房间的最短距离，取最小的

### 规则3：跨年级编排时按年级分开计算

**当前行为**：`auto_assign_preview` → `_allocate_gender_v4`
- 当前算法把同性别所有年级的班级合在一起计算
- 合班分组 `_build_combine_groups` 按 `grade|class_type` 分组（理论上不同年级不合班）
- **问题**：虽然合班不会跨年级，但班级排序和房间分配是混合的，可能导致跨年级房间交错

**用户要求**：先区分年级，一个年级一个年级计算，不同年级绝对不合班

**修复方案**：
- 在 `_allocate_gender_v4` 内部，按年级分组
- 每个年级独立执行9种情形尝试
- 年级之间房间不共享（按年级顺序分配连续房间段）

### 步骤1：修改班级排序规则（规则1）

**文件**：`room_assignment_v4.py` 第1423-1457行

**修改**：`_build_grade_aware_class_order` 函数

```python
def _build_grade_aware_class_order(active_classes, profiles=None):
    """
    构建年级有序 + 班号升序的班级列表

    排序优先级：
      1. 年级：年份升序（老生在前，获得低楼层）
      2. 班号：同年级内按班号升序（01→02→03...）

    注意：不再按班型聚集，所有班级统一按班号排序
    """
    def sort_key(item):
        cls, count = item
        grade_year = _extract_grade_year(cls.get('grade', ''))
        class_num = _extract_class_number(cls.get('class_name', ''))
        return (grade_year, class_num)

    return sorted(active_classes, key=sort_key)
```

### 步骤2：修复合班房间位置（规则2）

**文件**：`room_assignment_v4.py` 第1165-1222行

**修改**：`_pick_combine_room` 函数的兜底逻辑

```python
def _pick_combine_room(room_pool, class_assignments=None, class1_key=None, class2_key=None):
    """
    从可用房间中选一个合班房间
    优先级1：两个班级房间之间的位置
    优先级2：离两班边界距离之和最小的空房
    优先级3（兜底）：离任一合班班级最近的空房（不再取剩余中间）
    """
    if not room_pool:
        return None

    if class_assignments and class1_key and class2_key:
        c1_rooms = class_assignments.get(class1_key, [])
        c2_rooms = class_assignments.get(class2_key, [])

        # 收集两个班级的所有房间
        all_class_rooms = list(c1_rooms) + list(c2_rooms)

        if all_class_rooms:
            def pos(r):
                return (r.building or '', r.floor or 0, _room_number_int(r.room_number))

            class_positions = [pos(r) for r in all_class_rooms]

            if c1_rooms and c2_rooms:
                # 两个班级都有房间：优先级1（之间）+ 优先级2（距离和最小）
                c1_sorted = sorted(c1_rooms, key=pos)
                c2_sorted = sorted(c2_rooms, key=pos)
                c1_last = c1_sorted[-1]
                c2_first = c2_sorted[0]
                p1 = pos(c1_last)
                p2 = pos(c2_first)
                if p1 > p2:
                    p1, p2 = p2, p1

                # 优先级1：在两个班级之间找空房
                if p1[0] == p2[0]:
                    between = [r for r in room_pool
                               if (r.building or '') == p1[0] and p1 <= pos(r) <= p2]
                    if between:
                        mid_floor = (p1[1] + p2[1]) / 2
                        mid_num = (p1[2] + p2[2]) / 2
                        between.sort(key=lambda r: abs((r.floor or 0) - mid_floor) * 1000 +
                                     abs(_room_number_int(r.room_number) - mid_num))
                        return between[0]

                # 优先级2：离两班边界距离之和最小
                def dist(r, p):
                    b_diff = 10000 if (r.building or '') != p[0] else 0
                    f_diff = abs((r.floor or 0) - p[1]) * 100
                    n_diff = abs(_room_number_int(r.room_number) - p[2])
                    return b_diff + f_diff + n_diff

                return min(room_pool, key=lambda r: dist(r, p1) + dist(r, p2))

            # 优先级3（兜底）：离任一合班班级最近的空房
            def dist_to_nearest_class(r):
                rp = pos(r)
                min_dist = float('inf')
                for cp in class_positions:
                    b_diff = 10000 if rp[0] != cp[0] else 0
                    f_diff = abs(rp[1] - cp[1]) * 100
                    n_diff = abs(rp[2] - cp[2])
                    d = b_diff + f_diff + n_diff
                    if d < min_dist:
                        min_dist = d
                return min_dist

            return min(room_pool, key=dist_to_nearest_class)

    # 完全无参考时取剩余房间的中间
    mid = len(room_pool) // 2
    return room_pool[mid]
```

## 四、风险评估

1. **步骤3（按年级分开）** 风险最高：
   - 可能导致房间分配不够灵活（某年级房间不足时无法借用其他年级）
   - 但用户明确要求"不同年级绝对不合班"，这是硬约束

2. **步骤1（去掉班型聚集）** 可能影响强基班连续性：
   - 强基班房间号必须连续的硬约束仍由 `_pick_consecutive_rooms` 保证
   - 只是排序顺序变了，不影响连续性
