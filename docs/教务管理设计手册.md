# 教务管理设计手册

> 版本：v1.17.0（2026-09-21）｜状态：**开发中**（占位文档，待补全文）
> 所属模块：`academic`（独立库 `academic.db`）｜页面前缀：`/academic`
> 文档体系：`设计文档.md`（总手册）→ 本手册（模块手册）

## 1. 模块定位与边界

**做什么：**
- 教师名单（基础数据）：Excel 导入、随机唯一编号、身份证加密可后补、账号自动匹配/建号
- 查课统计：巡课记录录入与按年级/教师统计
- 教师业绩库：证书/课题/论文/荣誉/培训记录的录入与审核（教师工作台提交 → 教务审核）
- 学期课表（v1.16.0 起）：学期档案 / 节次配置 / 班级·年级·教师·大课表 / 导入导出 / 调课申请与执行 /
  校历与教学周 / 跨学期对比 / 使用情况报告 / 变更历史（版本快照）/ 打印
- 表单与填报汇总（v1.16.0 起，`/academic/forms`）
- 为教师评分与教师工作台提供基础数据支撑（规划）

**不做什么：** 不直接管理登录账号的密码/权限（账号体系归系统管理）；不做自动排课算法
（只做手工排课 + Excel 导入 + 调课流程）。

## 2. 数据库设计（academic.db，5 张表）

| 表 | 说明 |
|----|------|
| `teachers` | 教师名单（`teacher_uid` 随机唯一编号、姓名、身份证密文 id_card_enc（唯一可空）、手机号、学科、状态、user_id 快照） |
| `timetables` / `timetable_entries` | **旧版**课表档案（学期/年级）+ 明细（1-10 节，无冲突检测） |
| `data/timetable.db`（独立库） | **新版学期课表**：`term_schedules`（学期/起止日期/教学周）、`period_defs`（13 节作息）、`schedule_entries`（条目，含周次范围与软删除）、`schedule_swaps`（调课）、`schedule_versions`（版本快照） |
| `inspection_records` | 查课记录（日期、**年级**、节次、教师、班级、科目、结果、检查人、备注） |
| `teacher_achievements` | 教师业绩（类别、名称、级别、取得时间、颁发单位、状态：待审核/已通过/已驳回、提交人/审核人） |

**快照关联：** `user_id` → `system.db / users`（教师账号关联）；`teacher_uid` 为教务侧主标识。

## 3. 权限与数据范围

**子功能三档（permission_map.py）：** 查看（`academic.view`：名单/查课/业绩/课表查看 + 模板下载）/ 录入管理（`academic.edit`：教师导入编辑、查课录入删除、业绩录入审核）。
**数据范围：** 用户级 `UserDataScope` → 查课记录与课表按授权年级过滤（教师名单/业绩为全校基础数据，保持可见）；组级回落支持。
**典型身份：** 教务员（成绩/教务写入 + 学生/积分只读，按勾选年级如"仅 2025 级"）；教务主任（全校写入）。

## 4. 核心流程与页面

- **教师名单** `/academic/teachers`：下载模板 → 上传解析（匹配优先级：身份证 > 手机号 > 姓名）→ 预览确认（新增/更新/冲突/建号计划）→ 落库 + 初始密码清单（CSV）；支持搜索、编辑（身份证仅管理入口可更新）
- **查课** `/academic/inspection`：录入（日期/年级/节次/教师/班级/结果）→ 列表筛选 → 月度统计（次数/异常/按教师）
- **业绩库** `/academic/achievements`：教务录入（直接生效）/ 审核教师提交（通过/驳回）→ 列表筛选
- **学期课表** `/academic/schedule`：学期管理（草稿→启用→归档，归档写快照）→ 节次配置 → 排课
  （点击格子新增/编辑，支持单双周同格多条、班级与教师冲突检测、Excel 导入导出）→ 大课表/年级/班级/教师视图
  （可打印）→ 调课申请与审核执行 → 校历/使用报告/跨学期对比/变更历史
- **旧版课表** `/academic/timetable`：保留只读入口，功能由新版取代

## 5. 与其他模块的数据交互

- **读入：** `system.db / users`（账号匹配：手机号 == username 优先，姓名唯一匹配；`UserDataScope` 数据范围）
- **复用成绩模块服务：** `grades/services/user_account.py`（拼音建号 + 随机密码）——教务导入自动开户共用
- **对外提供：** 教师工作台（我的信息/我的业绩/我的课表，`teachers.user_id` 关联）；成绩模块任课映射经 user_id 自动打通（名单页显示映射数）

## 6. 故障隔离自检

| 场景 | 影响面 |
|------|--------|
| `academic.db` 损坏 | 教务页面报错；教师工作台显示"未关联"提示；成绩/宿舍/系统管理不受影响 |
| 写入范围 | 仅 `academic.db`；建号时写 `system.db`（经用户服务，失败仅该行跳过） |
| 依赖 grades 服务 | 代码级依赖 user_account（若成绩模块代码异常，教务导入受影响；只读使用不涉及数据耦合） |
