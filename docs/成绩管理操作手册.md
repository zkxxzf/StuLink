# StuLink 成绩管理与可视化分析 · 操作手册

> 适用版本：v1.9.0　｜　读者：管理员、年级长、班主任、任课教师
> 本文档说明**界面操作**，不解释指标算法。指标口径见文末《附录：口径与术语》。

---

## 1. 入口与导航

登录后，左侧菜单「成绩管理」下有三个入口（按您账号的权限显示/隐藏）：

| 菜单 | 权限 | 作用 |
|---|---|---|
| 成绩分析 | `grades.view` | 四大分析页（表格 + 图表 + 导出 + 打印 + AI 分析） |
| 考试管理 | `grades.edit` | 新建考试、导入成绩、浏览/修正成绩、删除考试 |
| 任课教师映射 | `grades.teachers` | 维护「班级 × 科目 → 教师」映射（教师分析的数据来源） |

> 划线分层配置入口在**考试管理 → 考试详情**，不在左侧独立菜单。

---

## 2. 角色与可见范围

系统按账号角色 + 权限组决定能看到什么，**成绩数据互不可见越界**。

| 角色 | 能看到的分析页 | 考试 / 数据范围 | 特别说明 |
|---|---|---|---|
| 管理员 | 年级 / 班级 / 学科 / 任课教师 四个 tab | 全部年级全部考试 | 默认进入「年级分析」 |
| 年级长 | 四个 tab | 仅本年级 | 年级下拉锁定为本年级 |
| 班主任 | 仅「班级分析」 | 仅所辖班级 | 班级下拉锁定；可看「本班 vs 年级均值」对标基准 |
| 任课教师 | 仅「任课教师」 | 仅本人任教的「班级 × 科目」组合 | 可下钻看所带班科的学生排名 |

- 没有可看权限时，分析页会提示「您没有成绩查看权限」。
- 任课教师映射未维护时，「任课教师」页无数据，管理员/年级长会看到维护引导。

---

## 3. 标准作业流程（一图）

```
考试管理 → 新建考试
   →（考试详情）下载模板 / 上传成绩 → 预检报告 → 确认导入（自动重算排名）
   → 划线分层配置（保存划线）
   → 成绩分析（四 tab 查看 / 导出 Excel / 打印 PDF / 可选 AI 分析）
```

班主任、任课教师通常**只做最后一步「成绩分析」**，前面的考试与成绩由管理员/年级长维护。

## 4. 考试管理

### 4.1 新建考试

1. 进入「考试管理」→ 点右上角 **新建考试**。
2. 填写：
   - **年级**（必选，格式如 `2026级`）
   - **考试名称**（必填；建议含日期，如 `2026级 期中 2026-03-15`）
   - **考试日期**（默认今天，决定「历次考试」排序与折线 X 轴）
   - **考试类型**（月考 / 期中 / 期末 / 联考 / 开学考 / 模拟 / 其他）
3. 点 **创建**。同年级**不允许同名考试**（避免成绩分散到两场），重复会拦截。

> 考试状态：`未导入`（draft）/ `已导入`（imported）/ `待重算`（dirty，单条改分后）。

### 4.2 考试列表

列表按考试日期倒序，显示每场考试的**参考人数**与状态。顶部可按年级筛选。点考试名进入详情。

### 4.3 考试详情（浏览 / 修正 / 重算 / 删除）

详情页按班级、按方向排名展示全体学生成绩（含总分、各单科、方向排名、进退步；借读生有学籍徽标）。

- **单条修正**：在对应成绩格点「编辑」改分或补录；设为空=视为缺考删除。改分后考试变 `待重算`。
- **重新计算排名**：单条修正或补录后点此按钮，整场重算排名与进退步，状态恢复 `已导入`。
- **删除考试**：需输入**考试名称**二次确认；级联删除该场全部成绩与划线（不可恢复，建议先备份数据）。

## 5. 成绩导入

### 5.1 下载模板

在「考试详情」或「导入向导」右上角点 **下载成绩导入模板**，得到含 3 个 sheet 的 Excel：

- **模板 A（全年级全科）**：`学号 姓名 年级(可选) 班级(可选) 总分(可选) 语文 数学 外语 物理 历史 化学 生物 政治 地理`
- **模板 B（分批次分科）**：只含要导入的若干科目列
- **填表说明**：列名与口径说明

### 5.2 填表要点（必读）

1. 第一行是表头，**不能改列名、不能删**；列顺序随意；缺考科目留空单元格；0 分填 `0`。
2. **学号必填**，系统以学号匹配学生；姓名/班级只用于展示与分批范围说明。
3. **年级列可选**：填了就必须与考试年级一致（如 `2026级`），不一致的行会被拦截为错误。不填则按考试年级处理。
4. **总分列可选**：填了优先采用外部总分（兼容含听力的总分）；不填由系统按应考 6 科累加。
5. 科目列可只保留本次要导入的科目（**分批导入**），未出现的科目列不会被改动。
6. 历史方向班级不考物理/化学/生物，对应格留空即可；也可直接粘贴参考 Excel 整表，多余列自动忽略。
7. 学号匹配不到、分数越界（负分或超满分）的行会进错误报告，可下载明细修改后重传。

> 应考 6 科 = 语数外 + 方向科（物理/历史二选一）+ 选科组合中 2 门再选科；超出应考的科目行会被忽略。

### 5.3 导入向导

1. 考试详情 → **导入成绩**，进入向导。
2. **选文件** → 选导入模式：
   - **模式 A：增量覆盖（推荐）**：文件出现的（学生×科目）覆盖旧成绩；文件为空的科目视为缺考删除；**文件未出现的科目与学生保留不动**。可选勾选「一并移除本次文件中未出现的原有学生成绩」（慎用，用于纠正错导人员）。
   - **模式 B：整场重置**：清空本场全部成绩后仅按本次文件导入（上次整体导错时用）。
3. 点 **解析并预览差异**。

### 5.4 预检报告（关键确认环节）

报告展示：

- 识别结果（模板 A/B、是否含总分列、科目列、是否含年级/班级列、忽略列）
- 统计卡：**可导入人数 / 错误行数 / 整行无分（未参加）/ 将新增学生 / 将更新条数 / 将删除（缺考）条数 / 未出现保留人数**
- **错误行**（如有）：列出「行号 / 学号 / 原因」，可点 **下载错误明细** 导出 xlsx 修改后重传
- 确认前请核对「将更新 / 将删除 / 未出现保留」是否符合预期——这是防止误覆盖的最后一道关。

点 **确认导入**（弹窗二次确认）→ 系统事务写入并**自动重算排名与进退步**，状态变 `已导入`。

> 一次导入最多 16MB；文件仅在内存解析，不落盘。

## 6. 划线分层配置

入口：**考试详情 → 划线分层**（需 `grades.settings` 权限，管理员/年级长可用）。

本页为单一矩阵，一次考试一套标准。配置后班级/学科分析里的「分层统计」「分层参考线」才会显示。

### 6.1 页面控件

- **下界方式**：
  - `固定分数`：直接填分数（如 549）。
  - `人数比例%`：填百分比，系统按该组该科排名自动换算成对应分数（如 20 = 前 20%）。
- **录入形态**：
  - `分科`：各科分别填线（选科后按物理类 / 历史类分两组列，两组可不同）。
  - `全科统一`：一套值套所有科。
- **含总分**（默认勾选）：矩阵是否包含「总分」这一列。
- **快速填层名**：一键填「四层（优秀/良好/及格/待提升）」或「高考线（清北/985/211/特控/本科/未上线）」——只填层名，不自动算线。
- **新增层**：手动加一层。

### 6.2 填写与保存

1. 先用「快速填层名」生成层，再在格子里填各层的下界值。
2. 同一层内下界需**从高到低**（如优秀 549、良好 500、及格 454、待提升 0）。
3. 切「固定分数 / 人数比例」会**清空已填数值**（两者含义不同，120 分≠120%），系统会弹确认。
4. 点 **保存划线** 前，前端会逐列预校验（层名非空、下界递减、比例 0–100、非负）；有问题会一次列出全部问题，不会提交后才报错。
5. 保存成功提示「已保存」。

> 行=层（第 1 层最高），列=科目。留空的格子不划线，也不会改动已有设置。

## 7. 成绩分析（四 tab）

入口「成绩分析」。默认按权限进入第一个可见 tab 并自动选中最近一场已导入考试。

### 7.1 顶部筛选栏

| 控件 | 说明 | 出现时机 |
|---|---|---|
| 年级 | 选择年级 | 未锁定的账号 |
| 考试 | 选择考试（含日期与状态） | 始终 |
| 方向 | 全部 / 物理 / 历史 | 年级分析、学科分析 |
| 班级 | 选择班级 | 仅「班级分析」 |
| 科目 | 选择科目或全部 | 仅「学科分析」「任课教师」 |

切换任意筛选即联动刷新当前页签（loading 态）。年级/考试为空时引导去考试管理。

### 7.2 四个页签内容

表格可点「折叠/展开」收起；图表为 ECharts 交互图，可悬浮看数值、图例可开关、窗口缩放自适应。

**年级分析**（横向对比全部班级）
- 表格：年级各班汇总表（参考人数/总分均值/标准差/最高最低/分层计数）、年级科目总表、年级分数段分布表、年级名次段分布表、历次考试总览表
- 图表：各班总分均值对比柱状图（含年级均值线）、年级分数段人数堆叠柱状图、各班总分箱线图、历次考试平均分多折线图

**班级分析**（单班内部，对比年级基准）
- 表格：班级概况表、班级-年级科目对标表、班级学生历次成绩明细表（含进退步，可看方向排/班排）、班级分层统计表
- 图表：本班各科 vs 年级各科柱状图、本班总分直方图、班级历次走势折线图（含年级参照线）、班级各科能力雷达图（得分率）

**学科分析**（以科目为中心，跨班级跨考试）
- 表格：学科各班对比表、学科历次考试统计表、总分分层内该科得分统计表
- 图表：班级×科目平均分热力图、同科各班得分对比柱状图、单科历次均分/及格率双轴折线图

**任课教师**（仅客观数据，不做主观评价）
- 表格：教师教学数据表（班均分/年级均分差/及格率/优秀率）、教师历次考试跟踪表
- 图表：同科目不同教师柱状对比图、所带科目历次走势折线图

> 变动列（分数变动/排名变动/与年级均分差）以**颜色**客观标注（进步绿、退步红），不出现任何评价性文字。

### 7.3 导出与打印

- **导出 Excel**：导出当前页签全部表格（多 sheet，含口径说明）。权限跟随 `grades.view`。
- **打印 / PDF**：调起浏览器打印，仅打印**当前激活页签**；在打印对话框选「另存为 PDF」即可。打印样式已隐藏菜单/工具栏/按钮。

### 7.4 空态与排查

- 选了 `未导入` 的考试：提示「暂无数据：该考试尚未导入成绩」。
- 班级分析选了未配置划线的考试：分层相关表占位「未配置分层」，其余表正常。
- 控制台报错或数据不刷新：**先按 `Ctrl+F5` 强制刷新**（开发/缓存导致旧页面）。

## 8. 任课教师映射

入口「任课教师映射」（需 `grades.teachers` 权限）。这是「任课教师」分析的数据来源。

### 8.1 网页矩阵维护

1. 选**年级**（按年级独立维护）。
2. 矩阵：**行=科目，列=班级**，单元格下拉选教师账号（来源「系统管理-教师管理」，仅已启用账号）。
3. 快捷：
   - **整行设为**：把某科目所有班级设同一教师（如带 01–05 班同科）。
   - **整列填充**（列头↓）：为该班全部科目指定同一教师（输入姓名或账号，留空=清除）。
4. 点 **保存全部**：预览「绑定/变更/停用」数量并生效。

### 8.2 批量导入教师安排表

1. 点 **批量导入教师安排表** → 下载同构模板或上传学校《教师安排表》。
2. 解析按年级分段（英语→外语别名，非高考科目/正副班/教室等列忽略）。
3. 逐 (年级,班,科) 按**姓名**核对账号：
   - 命中启用账号 → 绑定；
   - 账号停用/重名 → 错误行；
   - 无账号 → **自动开户**（姓名固定、账号=拼音可改、随机初始密码，首次登录强制改密）。
4. 预览开户清单（密码仅此一次可见，可下载《账号开通清单》）→ 确认后建号+写入映射。
5. 教师真实姓名（real_name）**不可修改**（身份锚）；账号（username）可改。

## 9. AI 分析（可选，需自备或管理员公共 API Key）

> **数据提醒**：分析时本次与上次两次考试的原始成绩（学号/姓名/各科分数/总分/排名/进退步）会发送到 AI 服务商，**离开学校内网**。请确认符合数据使用规定；本报告仅供参考，不代表学校评价结论。

### 9.1 配置 Key

- **个人 Key**（推荐）：点分析页「AI 分析」→ 无 Key 时引导填写 → 选服务商（DeepSeek 推荐 / 自定义 OpenAI 兼容）、填 API Key 与模型 → 保存。Key **加密存储，仅本人可见**，走您自己账户额度。
- **管理员公共 Key**：管理员可在弹窗里「配置全局公共 AI Key」，之后所有未配个人 Key 的用户自动使用它。

### 9.2 生成报告

1. 先选好要分析的**考试**。
2. 点 **AI 分析** → 弹出「发送确认」：展示本次考试、对比考试（上次同方向）、发送范围、学生人数、使用密钥。
3. 点 **生成 AI 报告**（约 30–90 秒）→ 报告渲染到当前页签顶部，可**复制**或**关闭**；同时写入历史。

### 9.3 报告历史

点分析页「AI 报告」进历史页：本人报告（管理员看全部），可按考试筛选、查看详情、删除。

## 10. 常见问题（FAQ）

**Q1 分析页年级/考试下拉是空的？**
先确认该年级已有 `已导入` 状态的考试（考试管理里看状态）。仍是空 → 按 `Ctrl+F5` 强刷。

**Q2 切换 tab 后内容错位 / 大片空白？**
多为浏览器缓存旧页面，强制刷新（Ctrl+F5）即可。

**Q3 导入后排名没变 / 进退步不对？**
单条改分或补录后，记得在考试详情点**重新计算排名**。整场确认导入会自动重算。

**Q4 分层表不显示 / 学科图没有参考线？**
先到考试详情做**划线分层配置**并保存。

**Q5 改了分数/划线但分析页数字没更新？**
分析接口有短缓存，稍等刷新；或强刷页面。

**Q6 保存划线提示「页面已过期或安全校验未通过」？**
页面打开太久/服务器重启致安全令牌失效，刷新页面（Ctrl+F5）后重试。

**Q7 班主任/任课教师看不到某些 tab？**
属正常权限限制（见第 2 节），非故障。

## 附录：口径与术语

- **年级**：`2026级` 格式，不认「高三/高二」称谓。
- **方向**：物理 / 历史（选科方向，排名/分层/上线均按方向内计算，互不可比）。
- **应考科目**：语数外 + 方向科 + 选科组合 2 门再选科，共 6 门。
- **参考学生 / 参考数**：本场至少一门应考科有分的学生；**借读等学籍状态不剔除、不影响统计与排名**，仅作徽标标注。
- **缺考**：应考科目无成绩（单元格留空），计 0 参考、不参与该科统计。
- **方向排名**：物理类/历史类内部各自按总分降序排名，同分同名次（竞争排名，顺延跳号）。
- **进退步**：本次方向排名 − 上次同方向考试方向排名（负数=进步）；首场/无上次为「—」。
- **分层 / 层**：按总分把方向内参考学生切分为有序若干层（默认四层：优秀/良好/及格/待提升），层名与层数可配。
- **科目三线**：优秀线/及格线/低分线，默认 = 满分的 90% / 60% / 40%（语数外满分 150，其余 100），用于优秀率/及格率/低分人数。
- **得分率**：科目均值 ÷ 该科满分（雷达图等跨科可比用）。
- **分数段**：总分等距分段（默认 30 分一档），仅显示非空段。
- **名次段**：方向内名次区间（默认 1–10/11–20/…/201+）。
