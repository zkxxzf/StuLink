## 1. 模块定位与边界

**做什么：**
- 考试数据管理：考试创建（状态机 draft/imported/dirty）、成绩 Excel 导入（双模板识别、分批覆盖、差异预览）、排名计算（方向内排名）
- 四大分析：年级分析 / 班级分析 / 学科分析 / 任课教师分析（表格 + ECharts 图表）
- 自由透视表：行/列/指标任意组合的交叉表分析
- 划线分层：总分线、单科三线（模板批量应用，比例自动换算为分数线）
- 成绩汇报区：面向校级汇报的五大板块表格 + PPT/HTML 交付物导出
- 考务管理：考场编排（考号规则、选科分组、固定考场）与打印交付（桌签/名单 PDF）
- 个人成绩查询与成绩证明：按权限查询学生成绩、生成带防伪码的证明（公开核验）
- AI 分析（BYOK）：考题分析报告与多轮对话（个人 Key 或全局 Key，数据按权限收敛）

**不做什么：**
- 不修改学生基础信息（学号/姓名/班级等仅作快照引用，写操作只发生在 `grades.db`）
- 不承担教务排课、日常考勤（教务模块职责）
- 成绩证明核验页为公开只读端点（限流 + 脱敏），不做登录要求
- **不做主观评价**：界面不出现对教师/班级/学生的评价性文字，只呈现数值（变动列仅用颜色标注）

## 2. 数据库设计（grades.db，15 张表）

| 分组 | 表 | 说明 |
|------|----|------|
| 考试数据 | `exams` | 考试主档（1 场考试 = 1 年级 × 1 次）；`status`：draft/imported/dirty；`config_json`：分数段宽 band_width、名次段界 rank_bands、科目三线 subject_lines 覆盖；`import_info`：最近导入批次摘要 |
| | `exam_scores` | 成绩明细**窄表**（一学生一科目一行，含伪科目"总分"行）；快照冗余（姓名/年级/班级/方向/选科），统计/排名无需跨库；唯一约束 `(exam_id, student_no, subject)`；排名列 rank_class/rank_dir/move_rank |
| | `exam_bands` | 划线分层（考试 × 方向 × 科目 × 层序 seq；seq=1 最高层无上界；subject='总分' 为总分线）；`lower_mode`：score/ratio（换算后落库为 score） |
| | `band_templates` | 划线模板（比例/分数模式、层定义、适用考试类型） |
| 教师映射 | `teacher_subject_links` | 年级 × 班级 × 科目 → `user_id`（唯一约束 (年级,班,科)；active 停用保留历史） |
| AI 分析 | `ai_keys` / `ai_global_keys` | 个人/全局 API Key（AES 随机 IV 加密存储，接口只回显掩码 sk-****后4位） |
| | `ai_reports` / `ai_chat_messages` | 分析报告（快照固化，含图表数据；本人可见，管理员可见全部）/ 多轮对话 |
| 成绩证明 | `certificates` | 证明记录（防伪码、快照 content_json（落库前 AES 加密 enc:: 前缀）、生成人/时间、作废标记） |
| | `cert_signing_keys` | HMAC 签名密钥（AES 加密落库） |
| 考务 | `exam_affairs` | 考务批次（编排模式 0/1/2、选科前缀、状态机） |
| | `affair_rooms` / `affair_students` | 考场 / 考务学生（含编排结果：考场/座号/考号） |
| | `affair_room_libs` | 考场房间库（跨批次复用） |

**快照关联（跨库无外键）：**
- `student_no`（学号）→ `system.db` 的 `students`：成绩、考务均以学号快照关联，学号不可变
- `user_id` → `system.db` 的 `users`：任课映射与报告归属；被教务模块经 `user_id` 读取（教师任课映射数）
- 换班/转科不影响历史考试统计（"当时在哪个班就以哪个班统计"）；主库改名不追溯历史成绩姓名

**索引要点：** `exam_scores` 按 (exam_id, subject, class_name)、(exam_id, student_no) 及覆盖索引 (student_no, subject, exam_id)（v1.13.2 性能优化）；`exam_bands` 唯一约束 (exam_id, direction, subject, seq)。

## 3. 权限与数据范围

**功能权限（权限管理页 · 子功能三档，permission_map.py）：**

| 子功能 | 只读 → keys | 写入 → 追加 keys |
|--------|------------|-----------------|
| 查看分析 | `grades.view` | —（只读即全部） |
| 教学管理 | — | `grades.edit`、`grades.import`、`grades.settings` |
| 任课映射 | — | `grades.teachers` |
| 个人成绩查询 | — | `grades.student_query` |

**数据范围（两层判定，用户级优先）：**
1. 用户级：`UserDataScope`（权限管理页第二张表勾选年级）→ `scope.py:user_grade_scope`
2. 组级回落：权限组 `scope_type`（school/grade/class）+ `user.grade` / `UserClassLink` / 任课映射

**守门函数（所有分析/汇报/导出/查询 API 共用）：**
- `visible_grades(user)`：可见年级（下拉/筛选）
- `check_exam_visible(user, exam)`：考试可见性（越界 403；**无有效范围一律拒绝**）
- `student_in_scope(user, student_no)`：学生级可见性（个人查询/证明）
- 汇报区另有 `_guard_report`（班主任/任课教师不开放年级汇报）；分析 tab 有 `_guard_tab` 可见矩阵

**角色可见矩阵（与算法手册第 2 章口径决策联动）：**

| 用户 | 可见 tab | 数据范围 |
|---|---|---|
| 管理员 | 四大 tab 全部 | 全部未毕业年级全部考试 |
| 年级长 | 四大 tab | 仅本年级（年级下拉锁定） |
| 班主任 | 仅班级分析 | 仅所辖班（可看本班 vs 年级均值对标） |
| 任课教师 | 仅任课教师（本人组合）+ 本人班科学生排名下钻 | 仅本人映射 (班×科, active) |

## 4. 核心流程与页面

### 4.1 考试与成绩
1. 创建考试（年级 + 日期 + 类型；同名阻断）→ 2. 下载导入模板（模板 A 全科含总分列 / 模板 B 分科；填表说明）→ 3. 上传解析（**预检不落库**，返回 import_token + 差异预览：新增 X 人/更新 Y 条/缺考删除 K 条/未出现保留 P 人/错误 E 行，可下载错误明细）→ 4. 确认导入（事务写入 + 整场重算排名与进退步）→ 5. 单条修正（改分自动重算该生总分；状态置 dirty）→ 6. 重新计算排名（dirty → imported）

**导入状态机（防误覆盖/并发）：**
```
draft(新建) ──上传+确认──> imported ──单条修正/再次上传──> dirty ──重算/确认──> imported
      └──────────────────< 删除考试（级联）
```
- 模式 A 增量覆盖（日常）：影响范围 = 文件出现的 (学生 × 科目列)；单元格空 = 该科本次缺考（删旧行）；**文件未出现的科目列保留不动**（支持分批补导）；未出现学生默认保留（可勾"一并移除"纠错）
- 模式 B 整场重置（纠错）：清空全场按本次文件重导（输入考试名强确认）
- 上传 16MB 上限，仅内存解析（BytesIO），不落盘；token + 整场事务双重防串批；每次导入写 import_info + OperationLog

**导入解析校验**：表头识别失败/缺学号列 → 整批报错引导模板；年级列不一致 → 行错误（防跨年级混入）；分数越界（非数值/负分/超满分+0.5）→ 行错误；学号未匹配 → 行错误；非应考科目 → 忽略；全行无分 → 提示未参加；**错误行不阻断整批**；借读等学籍状态不剔除仅标注。

### 4.2 划线分层
模板选择（比例制：按参考人数换算分数线；分数制：直接指定，层名可改）→ 应用至考试（按方向/科目独立，考试与模板绑定）→ 分层结果进入各分析与汇报口径。层判定/比例换算/三线口径见[算法手册第 4 章](成绩分析算法手册.md)。

### 4.3 分析（4 个 tab + 方向筛选）
**分析视图全清单（A1~A4，验收依据）：**

| 模块 | 表格 | 图表 |
|---|---|---|
| A1 年级分析 | T1 各班汇总（分层计数动态列）、T2 科目总表、T3 分数段分布、T4 名次段分布、T5 历次考试总览 | G1 班均分对比柱（含年级均值线）、G2 分数段堆叠、G3 班级箱线、G4 历次多折线 |
| A2 班级分析 | T1 班级概况（含年级差）、T2 班-年级科目对标、T3 学生历次明细（含进退步）、T4 分层统计（各层科目均分） | G5 本班 vs 年级柱、G6 总分直方、G7 历次走势（含年级参照线）、G8 各科得分率雷达 |
| A3 学科分析 | T1 学科各班对比、T2 历次统计、T3 总分分层内该科得分 | G9 班级×科目热力、G10 同科各班对比、G11 历次均分/及格率双轴 |
| A4 任课教师 | T1 教师教学数据（班均分/年级差/及格率/优秀率）、T2 历次跟踪 | G12 同科教师对比、G13 本人走势 |

- 导出：各 tab 一键导出 Excel（多 sheet，首 sheet 含口径说明；权限随 grades.view）
- 打印：浏览器打印仅当前激活 tab（A4 横向、表格分页表头重复、图表固定打印宽）
- 图表主题：蓝 #3b82f6 系，物理蓝/历史紫分色；所有均值/率保留 1 位小数，排名整数；空值"—"，变动列仅颜色不评价

### 4.4 自由表（pivot）
行维度（班级/科目/层）× 列维度 × 指标（人数/均分/去差均分/上线/双上线/层内占比…）任意组合

### 4.5 汇报区（v1.13.x）
- 板块一 各科层上线（含对比考试与去差均分）｜板块二 班级概况｜板块三 单班各科｜板块四 单科各班｜板块五 压线提醒（临界生名单，含班主任/方向排名）
- 列级排名勾选、任课教师名次标注；交付物导出：独立 HTML / PPTX（python-pptx 服务端生成）
- 权限：仅管理员 / 校级 / 年级长（或用户级范围配置者）；缓存 15 分钟，改分/划线后统一失效

### 4.6 考务管理（v1.12.1+）
批次创建（批次名/年级/考试日期/模式0默认考号前缀）→ 学生名单（模板预填/导入；字段：学号、姓名、班级、选科组合、是否参与考试、固定考场、固定座号、自定义考号）→ 考场设置（编号/位置/适用选科/容量/前缀；"默认/通用/空"科目对所有选科开放）→ 编排（**模式 0**：前缀+考场号+座号；**模式 1**：考号=学号；**模式 2**：自定义；规则：先安置固定考场/座号学生，其余按选科分组、**同班邻座 ≤1**；容量不足日志提示）→ 导出（按班级/按考场名单、竖版桌签，格式与 Excel 宏一致）→ 成绩关联（绑定同年级考试后按考场查看总分/排名/进退步，缺成绩标"缺"）

### 4.7 个人成绩查询与成绩证明（v1.10 / v1.12.2）
按学生查询历次成绩与趋势 → 生成证明（快照固化 + HMAC 防伪码 SL+日期+随机码+签名段）→ 打印页/公开核验页 `/grades/cert/<code>`（IP 限流、脱敏展示：隐藏学籍号、身份证仅显示前3后4）→ 证明台账（作废管理）。快照 `content_json` 落库前 AES 加密（`enc::` 前缀，签名绑定明文，旧码兼容）

### 4.8 AI 分析（BYOK，v1.9.0 已实现）
- **Key 管理**：个人 Key（`ai_keys`，仅本人可见/更换/清除，加密存储掩码回显）＋管理员全局兜底（`ai_global_keys`）；服务商默认 DeepSeek，支持自定义 OpenAI 兼容地址
- **发送数据（权限收敛）**：只发**本次 + 上一次同年级考试**的原始成绩；管理员/年级长=全年级、班主任=所辖班、任课教师=本人任课（科目列只含任教科目）；发送前预览确认（考试/范围/人数/Key 来源），数据出内网前弹窗明示
- **报告**：落库 `ai_reports`（受限 Markdown 渲染防 XSS）；标注"AI 生成，仅供参考"；历史入口可按考试筛选/删除
- **转发**：标准库 urllib 直连（零新增依赖），180s 超时，错误码中文化；Prompt 强约束"仅依据提供数据，禁止编造"

### 4.9 任课教师映射
- 网页矩阵：选年级 → 科目行 × 班级列 → 单元格下拉选教师（仅启用账号）→ 整行设为/整列填充 → 保存全部（预览绑定/变更/停用）
- 批量导入（同构《教师安排表》横表）：多年级区段解析（英语→外语别名；忽略非高考科目/正副班/教室等列）→ 逐 (年级,班,科) 按**姓名**核对账号：命中启用 → 绑定；停用/重名 → 错误行；无账号 → **自动开户**（real_name 固定、账号=拼音可改、随机初始密码、强制改密）→ 预览开户清单（密码一次性可见，可下载《账号开通清单》）→ 确认生效

## 5. 与其他模块的数据交互

**读入（只读快照）：**
- `system.db / students`：学号 → 姓名/班级/选科（展示与统计）
- `system.db / users`：user_id → 任课映射展示、报告归属、成绩证明经办人
- `system.db / dict`：科目（exam_subject）/考试类型（exam_type）/分数段等字典

**对外提供：**
- 教务模块：教师名单页展示"任课映射数"（`teacher_service.lesson_map_count` 经 user_id 读取 `teacher_subject_links`）
- 教师工作台：个人成绩查询入口（受 `grades.student_query` + 数据范围控制）
- 学生画像（规划）：按学号读取成绩趋势（只读汇聚）

**代码级复用：** `services/user_account.py`（拼音建号 + 随机密码）被教务模块教师导入复用——该服务属"共享工具"性质，改动需同时回归两个模块。

**对 system 模块的联动（已实施）：** 教师真实姓名 real_name 不可修改（身份锚：任课核对/成绩归属/报表展示），用户管理姓名入口已锁定（前端只读 + 后端拒绝）。

## 6. 故障隔离自检

| 场景 | 影响面 |
|------|--------|
| `grades.db` 文件损坏/锁定 | 启动时逐库建表容错仅告警；成绩/汇报/考务/证明页面报错；**登录、系统管理、宿舍、教务（除任课映射数展示）不受影响** |
| 成绩模块写入 | 仅写 `grades.db`，无跨库写入、无跨库事务 |
| 读取 system 失败 | 成绩分析显示学生信息受限但不崩溃（快照字段优先） |
| AI 外呼失败 | 仅报告生成失败（错误提示），不影响其他功能 |
