  • 调课（可与同事换时间）
  • 请人代课
{% if active == 'apply' %} 调课：选我的课 → 再选调到哪一格（列出当天全部节次）。目标格四类 —— 绿色＝自习空档（那节本班和我都没课，直接调过去）、 黄色＝那节有同事的课（点它就是和他换上课时间： 我俩各上各的班、只换时段，默认不用他确认，需要他同意就勾上清单里的选项）、 紫色＝那节是我自己的另一节课（点它＝把这两节互换，不需要谁确认）、 红色＝我在别处有课（换不了）。 一次可以选好几节，算一批提交、一次审批。只换上课时间，不换班级 / 教室 / 学生； 要请别人来上我的课请用「请人代课」。 {% else %} 请人代课：我的课请别的老师来上 —— 时间、班级都不动，只换授课人。 一次可以请多位老师代多节课，每位老师各自确认。 {% endif %}
