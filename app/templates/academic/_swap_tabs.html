  • 普通调课
  • 两人换课

{% if active == 'apply' %} 普通调课：把我自己的课挪到空档（那一节本班和我都没课）。一次可以选多节课，各自指定目标时段，教务审批后一起生效。 {% elif active == 'exchange' %} 两人换课：我和另一位老师互换。勾选「对调什么」决定换哪些内容 —— 都勾=整条互换（我去上他这节课、他来上我这节课）· 只勾时间=各上自己班，只把时段换过来 · 只勾班级=时间不动，两人去上对方的班。 一次可以和多位老师换多节课；每位老师各自确认后进入教务审批。 {% else %} 请人代课：我的课请别的老师来上（时间、班级都不变，只换授课人）。一次可以请多位老师代多节课。 {% endif %}
