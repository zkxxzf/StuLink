  • 调课（含与同事对调）
  • 请人代课
{% if active == 'apply' %} 调课：选我的课 → 再选调到哪一格。目标格有三类 —— 绿色＝空档（那节本班和我都没课，直接调过去）、 黄色＝那节有同事的课（点它就是和他换： 我上他那节、他上我这节，需要他点【同意】）、 紫色＝那节是我自己的另一节课（点它＝把这两节互换，不需要谁确认）、 红色＝我在别处有课（换不了）。 一次可以选好几节，也可以同时和好几位老师换，算一批提交、一次审批。 {% else %} 请人代课：我的课请别的老师来上 —— 时间、班级都不动，只换授课人。 一次可以请多位老师代多节课，每位老师各自确认。 {% endif %}
