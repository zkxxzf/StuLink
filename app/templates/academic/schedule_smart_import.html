① 全校总课表（行＝星期 × 节次，列＝班级）② 整班矩阵（一个 sheet 一个班）。
按「班级 + 周次」批量导入：填了就整批按该周次写入； 留空 = 按格内标注（缺省 1-18）。格内写有 (单周)/(3-5) 的以格内为准。
形态 ① 全校总课表（行＝星期 × 节次，列＝班级）：
┌──────┬──────┬────────┬────────┐ │ 星期 │ 节次 │ 高三1班 │ 高三2班 │ ├──────┼──────┼────────┼────────┤ │星期一│ 1节 │ 历史 │ 英语 │ │ │ │ 郭艳静 │ 王一楠 │ ← 格内第二行写教师（可省略） │ │ 2节 │ 语文 │ 语文 │ └──────┴──────┴────────┴────────┘
形态 ② 整班矩阵（一个 sheet 一个班，行＝节次，列＝星期）：
┌────────┬──────┬──────┐ │ 节次 │ 周一 │ 周二 │ ├────────┼──────┼──────┤ │ 第1节 │ 数学 │ 语文 │ │ │ 张伟 │ 李娜 │ └────────┴──────┴──────┘

  • 学科可简写：语/数/英/物/化/生/政/史/地/体/音/美/班/自习
  • 空值写 —、/、无 都可以；单双周写 语文(单周)
  • 教师按姓名自动匹配教师名单（找不到的按原样记录并提示）
